## 收录条件

收录不收费，满足下面四条的插件都可以提交：

- 代码放在公开的 GitHub 仓库里。
- 有 README，写清楚了插件的用途和安装方法。
- 带有开源许可证。
- 确实是为 DeepSeek Harness 写的，或者能在其中使用。

另外建议给仓库加上 `dsh-plugin` 这个 topic。这是官方项目给出的建议，方便其他人和工具找到你的插件。它不是在本站收录的必要条件。

## 怎么提交

发邮件到 [{email}](mailto:{email})，写明三项内容：

1. 仓库地址。
2. 你认为合适的分类。
3. 一句话简介，说明插件是做什么的。

有这些就可以开始处理了。

## 提交之后

1. 编辑查看仓库，对照上面的条件确认是否符合。
2. 编辑根据 README 撰写介绍。介绍是我们自己写的，不会照搬 README 原文。
3. 插件页面上线。

整个过程通常在几天之内完成。

## 几点说明

- 收录不收取任何费用。
- 不接受付费排名，也不接受付费换取展示位置。
- 被收录不等于带有“已核实”标记。这个标记是另外加的，要等编辑实际安装并确认插件能按文档运行之后才会有。

## 修改和下架

如果你是插件作者，可以随时要求我们更正介绍、调整分类或者下架页面。同样发邮件到 [{email}](mailto:{email})，并附上仓库地址，方便我们确认是哪一个插件。
