## What this site is

{brand} is a directory of plugins for [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness), the open-source agent harness from deepseek-ai, along with a set of tutorials for people learning to use it. The harness treats everything as a plugin, so finding the right ones matters. This site tries to make that easier.

The site is maintained by community members. It is not affiliated with, sponsored by or endorsed by DeepSeek, and nothing here is an official statement from the project.

## Where the data comes from

The numbers on each plugin page (stars, latest version, license and the date of the last push) come from the public GitHub data of that plugin's repository. They are refreshed periodically, so a figure may lag behind what GitHub shows right now. The repository itself is always the authoritative source.

## How descriptions are written

Each plugin description is written by an editor after reading the plugin's README. It is our own summary, not a copy of the README. We try to say what the plugin does, who it is for and how to install it. If you are the author and think we got something wrong, tell us and we will fix it.

## What "Verified" means

A plugin marked Verified is one an editor has installed and confirmed to work as its documentation describes, at the time of checking.

Two things to keep in mind:

- No mark does not mean a plugin has a problem. Most often it means we have not tested it yet.
- A mark is not a security guarantee. We check that a plugin runs as described; we do not audit its code. Plugins change after we look at them. Read the source before you install anything.

## Tutorials

The tutorials are based on the [official documentation](https://deepseek-harness.github.io/deepseek-harness/), and each one lists the sources it draws on. When the official docs and a tutorial disagree, trust the official docs and let us know.

## Reporting errors

If you find a mistake, such as an outdated description, a wrong category, a broken link or an error in a tutorial, email [{email}](mailto:{email}). Include the page address and what should change. We correct errors once we have confirmed them.
