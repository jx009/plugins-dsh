## 这个站是做什么的

{brand} 收录 [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness) 的插件，并提供一组入门和进阶教程。DeepSeek Harness 是 deepseek-ai 开源的 agent harness，它把几乎所有功能都做成了插件，所以用好它的前提是找到合适的插件。我们做这个站，就是想让查找和比较插件省事一些。

本站由社区成员维护，与 DeepSeek 官方没有隶属关系，也没有得到官方的赞助或背书。站内内容不代表项目官方的意见。

## 数据从哪里来

插件页面上的星标数、最新版本、许可证和最近推送时间，都取自对应仓库的公开 GitHub 数据。这些数据是定期更新的，所以可能比 GitHub 上的实时数字稍晚一些。有出入时，以仓库本身为准。

## 介绍是怎么写的

每个插件的介绍都由编辑阅读 README 之后独立撰写，不是 README 的原文照搬。我们尽量讲清楚三件事：这个插件做什么、适合谁用、怎么安装。如果你是插件作者，觉得介绍写得不准确，告诉我们，我们会改。

## “已核实”是什么意思

带有“已核实”标记的插件，表示编辑实际安装过，并确认它在核实当时能按文档说明运行。

需要注意两点：

- 没有标记不代表插件有问题，多数情况只是我们还没来得及测试。
- 有标记也不构成安全担保。我们确认的是它能按说明运行，并没有审计它的代码，而且插件在核实之后还会继续更新。安装任何插件之前，请自行查看源码。
