## What we list

Listing is free and open to any plugin that meets four conditions:

- It lives in a public GitHub repository.
- It has a README that explains what the plugin does and how to install it.
- It carries an open-source license.
- It is written for DeepSeek Harness, or can be used inside it.

We also suggest adding the `dsh-plugin` topic to your repository. This is a recommendation from the official project, and it helps other people and tools find your work. It is not a requirement for being listed here.

## How to submit

Email [{email}](mailto:{email}) with:

1. The repository address.
2. The category you think fits best.
3. A one-sentence summary of what the plugin does.

That is all we need to get started.

## What happens next

1. An editor looks through the repository and checks it against the conditions above.
2. The editor writes a description based on your README. We write our own text rather than copying yours.
3. The plugin goes live on the site.

This usually takes a few days.

## Things to know

- We do not charge for listings.
- We do not accept payment for placement or ranking.
- Being listed does not mean the plugin carries the Verified mark. That mark is added separately, after an editor has installed the plugin and confirmed it works as documented.

## Changes and removal

If you are the author, you can ask us at any time to correct the description, change the category or remove the listing. Write to the same address, [{email}](mailto:{email}), and include the repository address so we know which listing you mean.
