## DSHBox 是做什么的？

DSHBox 是一个支持本地运行和远程连接 DSH 的安卓开源应用，内置多种 DSH 插件。它面向需要在手机或平板上使用智能体的开发者，把终端、文件管理、网页自动化和手机操控集中到一个工作台，日常使用无需 Root 或 Termux。

本地模式通过 PRoot 与 Debian 沙箱运行服务；远程模式连接局域网或公网中的已有实例。它以 APK 发布，提供 DeepSeek Harness 插件管理入口，设备要求为 Android 10 及以上、ARM64 架构。

## DSHBox 核心功能

- **本地运行与双渲染**：所提供的 README 记载内置 DSH `0.2.2-rc.2` 运行层。系统 WebView 版体积较小；内置 GeckoView 158 的版本不依赖系统渲染内核。
- **远程配对与设备管理**：支持扫码或粘贴配对链接，确认后保存设备。端点可独立选择代理或直连模式，并设置会话保留策略，设备可按分组管理。
- **浏览器自动化**：随包 `browser-use` 提供 24 项工具，覆盖导航、内容读取、点击、输入和滚动等操作。也能预览沙箱内的 HTML，并把截图和选区意见提交给绑定会话。
- **Pilot 手机操控**：通过无障碍、Shizuku 和平台直连调用操作手机。随包 `@local/mobile-pilot` 提供 `phone_*` 工具，可按能力设置禁止、询问审批或完全访问。
- **插件管理与恢复**：Cordis 集中提供插件开关、市场及加载记录。第三方插件导致启动异常时，可使用安全模式或独立应急实例辅助修复。

## 怎么安装和使用 DSHBox？

从仓库发布页 `https://github.com/WSK-build/DSHBox/releases/latest` 下载 APK 安装。现有资料没有提供应用本身的 DSH 安装命令，也没有确认对应 npm 包名。

1. 先选安装包。系统 WebView 较新且正常时，可选体积较小的版本；内核过旧或升级困难时，选内置 Gecko 版。两种 APK 同包名、同签名，可覆盖切换并保留数据。
2. 启动应用，按新手引导准备精简 Debian 与 Node.js 环境。本地运行准备支持多镜像检测、失败重试和离线导入，完成后打开 DSH。
3. 在首页 DSH 卡片进入本地访问设置，可复制带 token 的完整地址、设置外部打开方式并查看运行时间。实际端口由启动前探测决定，不应固定使用 `3080`。
4. 连接已有实例时，打开「远程」页签，扫码或粘贴受支持的配对链接，核对确认卡片后建档，再按需要调整端点连接模式。
5. 在 Cordis 中管理「DSH浏览器自动化」和「DSH连接手机」开关。网页任务交给 Browser，原生应用任务使用 Pilot，并按需求配置能力审批。

## DSHBox 报错怎么排查？

页面空白、加载失败或工作区异常时，先检查系统 WebView 是否过旧。README 建议这类设备改用内置 Gecko 版；系统内核不支持 document-start 注入时，应用会阻止导航并提示升级。

首次环境准备失败，可重试、切换可用镜像或使用离线导入。第三方插件引发崩溃时，先用安全模式启动，再查看按启动分段记录的插件加载情况。首页卡片「更多」中的「应急修复与实例切换」可启动独立空白数据实例，修复主实例后再切回。

使用 `dsh-mobile` 配对时，iroh 传输地址会被明确拒绝，应按提示改用局域网或 Cloudflare 模式。Browser 对复杂跨页面任务恢复、长时流式响应及部分媒体和站点仍有限制，不能保证所有任务全自动完成。
