## deepseek-harness-orange-book 是做什么的？

 deepseek-harness-orange-book 是一本用实测记录讲解 DSH 启动、权限和工具编排的中文电子书，不是可安装的 DSH 插件。它从首次运行时会遇到的问题讲起：启动加载了什么，写文件前何时需要审批，一次任务的成本又该怎么看。想查 DeepSeek Harness 插件、技能与 MCP 各自负责什么，也可以从书里讲扩展机制的部分读起。

书中的 10 月更新基于 `0.2.1-rc.2` 预览版，作者在新的隔离目录里重新安装并测试。标有「8 月」的段落保留了早期结果。阅读时先认清记录属于哪个版本，再决定要不要在本机对照。

## deepseek-harness-orange-book 核心功能

- **启动清单与系统提示词**：收录完整系统提示词和一份 129 行的默认启动清单。前者用来看模型收到的指令，后者用来看启动时装载了什么；书中也把另行安装的扩展包单独列出。
- **三份原始会话日志**：分别记录标准模式、PTC 和创造模式。可以边读章节边顺着事件检查，分清模型发起了哪些操作、工具返回了什么，以及运行中出现了哪些审批。
- **PTC 编排与成本**：用一次模型写程序来编排工具的实测，说明模型调用次数和工具操作次数为什么要分开看。该次测试的固定开销反而增加，不能只凭调用次数判断是否省钱。
- **创造模式造工具**：通过 `count_chinese` 的例子记录新工具从生成、打包到审批安装的过程。10 月重测还检查了重启后是否保留，并与 8 月的结果作了区分。

## 怎么安装和使用 deepseek-harness-orange-book？

没有安装命令，也不需要在 DSH 中配置这本书。要阅读或对照书里的实验，可以按下面的顺序操作：

1. 打开仓库 README 的下载区，选择 PDF、为微信读书优化的 EPUB，或图片已内嵌的单文件 HTML。想按章节在线阅读，也可以从 README 进入 WorkBuddy 资料库。
2. 第一次使用框架，先读讲首次任务、权限和运行模式的「进门」部分；已经在使用框架，可以按问题查会话日志、成本章节或附录的命令速查。
3. 本机已有 DSH 且想对照启动清单，可在终端运行 `dsh --profile web --dump-default-config`。这条命令用于导出默认配置，不会安装电子书；对照时把启动项与书中另外列出的扩展包分开看。

## deepseek-harness-orange-book 报错怎么排查？

如果 PDF 在 GitHub 页面上显示不全，先下载文件再用本地阅读器打开。若只是想尽快查到某一段，也可以改用单文件 HTML 或 WorkBuddy 的章节页，不必为阅读问题修改 DSH 配置。

如果本机的系统提示词、启动清单或日志与书中不同，先确认 DSH 版本、运行时选用的 profile 和对应的实测月份，再以本机输出为准。若是另行安装的插件没有出现在预期位置，检查当前 profile 下是否已启用它，重启 DSH 后查看版本和日志。排查创造模式的重启结果时，记得区分 8 月的临时工具记录和 10 月经审批安装的插件包记录。
