## awesome-claude-video-skills 是做什么的？

awesome-claude-video-skills 是面向 DSH 插件选型的视频技能与工具目录，帮助开发者寻找可由编程智能体操作的视频制作项目。它涵盖 Claude Code、Codex 等智能体使用的技能和工具包，适合查找宣传片、讲解视频、剪辑及动态图形方案。对于寻找 DeepSeek Harness 插件的用户，它提供选型线索；现有 README 没有确认这些项目原生兼容该宿主。

目录按产出类型组织项目，包括框架、宣传演示、讲解、剪辑、竖屏短视频、数字人、故事动画、动态图形、脚本学习和音乐视频。README 报告收录 503 个仓库，与仓库描述中的 180 个不一致，因此不宜把数量作为固定规格。

## awesome-claude-video-skills 核心功能

- **按成片用途筛选**：先区分新建视频与处理现有素材，再查找字幕、B-roll、教程或动态标题工具，缩小候选范围。
- **Remotion 与 HyperFrames 选型**：目录包含渲染框架及相关技能。维护者建议希望自主设计画面的用户考虑 Remotion 官方技能，并给出明确设计方向。
- **统一任务测试参考**：十六项技能制作同一支 15 秒宣传片，要求五行固定文案、1920 × 1080 分辨率和每秒 30 帧。README 报告全部通过四项输出检查。
- **逐仓库安全评级**：项目称 Agent Skills Hub 已阅读并为每个仓库评级。提供的片段没有说明评级细则，无法据此推断某一级别的具体保障。
- **双语与在线筛选**：提供中英文文档，另有带筛选功能的在线目录，说明中的刷新间隔为八小时。

## 怎么安装和使用 awesome-claude-video-skills？

当前材料没有 DSH 安装命令，也没有确认 npm 包名，因此没有可直接复用的安装指令。

1. 明确成片目标。先决定是制作宣传片、讲解视频、竖屏内容，还是剪辑现有素材，再进入对应分类。
2. 查看推荐项目。追求快速完成可参考 explainroo；希望一个视觉主题贯穿全片可参考 onetake；需要自主设计可查看 remotion-dev/skills。
3. 阅读候选项目自己的 README。安装步骤、配置位置和宿主要求都应以该项目文档为准，目录没有提供统一配置文件。
4. 核对接入条件。文中测试使用 Claude Code，不能将测试成功直接视为 DSH 兼容证明。
5. 用明确的小任务验证。写清时长、尺寸和屏幕文案，生成后检查播放、规格、文字可读性和画面运动，再判断是否适合实际工作流。

测试耗时只对应文中的环境和任务。例如 HyperFrames 在该任务中耗时 23.5 分钟，这可以作为比较背景，不能当作所有视频的渲染时间。测试也没有对成片美观程度打分，仍需自己查看结果。

## awesome-claude-video-skills 报错怎么排查？

提供的 README 没有列出安装报错或专属修复方法。如果另行接入的工具未在 DSH 中出现，可按通用顺序检查：确认当前 profile 名、确认相关插件已启用、重启宿主，再查看版本和日志。这些属于环境检查，不代表目录提供了对应安装支持。

还应检查素材是否符合工具用途。README 指出 motion-graphics 面向人物口播素材，而统一测试没有提供这类输入；用途不匹配会影响参考价值，不一定意味着软件故障。

遇到具体渲染问题，应回到所选项目的文档查找依赖与配置说明。目录中的成功案例只覆盖指定任务，不能替代对实际环境和输入素材的验证。
