## mcp-server-fanqie 是做什么的？

mcp-server-fanqie 是一个支持番茄小说搜索、官网章节阅读和本人阅读数据查询的 DSH 插件。它让读者在侧栏完成搜书、查看目录和阅读，扫码后还能查看自己的书架与收藏划线，减少在阅读界面和会话之间切换。

仓库同时提供 MCP、独立 Skill、CLI 和本地 HTTP API，共用直接访问官方站点的本机数据核心。DeepSeek Harness 插件的独立包名是 `dsh-fanqie-reader`，与旧 MCP npm 包不同。新版移除了旧第三方服务器依赖，但仍需联网，官方接口或网页变化也可能影响可用性。

## mcp-server-fanqie 核心功能

- **番茄小说搜索**：在右侧栏搜索作品、查看封面和目录。小说公开搜索无需本人账号登录。
- **官网章节阅读**：打开网站可见正文，不保证覆盖 App 中的全部内容。锁定章节、未知字体和残余乱码会明确报错。
- **本人书架与划线**：官方扫码授权后查看自己的书架和收藏原文。共享账号核心还支持云端阅读位置，并区分划线与普通书签。
- **对话工具**：插件注册七个 `fanqie_*` 工具，可配合图形界面使用；它们与 MCP 的二十二个工具不是一一对应。
- **多入口查询**：MCP 和 Skill 提供书籍详情、分页目录及整本书的书评查询。其功能表不能直接视为侧栏插件的全部媒体支持范围。

## 怎么安装和使用 mcp-server-fanqie？

README 没有提供 DSH 安装命令，当前插件也尚未发布到 npm。请使用源码目录安装；旧 `@fysh925/mcp-server-fanqie` 包和历史 `0.2.0-dev.6` Release 均不包含该插件。

1. 克隆或下载当前仓库，保留完整的 `plugins/deepseek-harness/` 目录，包含其中的 `vendor/`。
2. 使用支持插件的 Harness 桌面端；README 记录了 `0.2.1-rc.5` 的桌面验证。
3. 在插件管理页选择该目录，或让会话中的智能体通过 `plugin_manager install_bundle` 安装目录的绝对路径。
4. 按需刷新或重启，从右侧栏「+」开始页选择「番茄阅读」。
5. 搜索小说，浏览目录并打开章节；查看个人数据时，进入「我的」，按官方提示扫码并在本人手机上确认。

插件 Host 直接调用内置核心，无需另开 API 服务。账号凭据默认保存在本机，核心支持用 `FANQIE_ACCOUNT_DIR` 指定位置；默认路径可能随打包环境变化。更详细的安装与卸载说明位于仓库的插件文档。

## mcp-server-fanqie 报错怎么排查？

- **侧栏入口没出现**：确认安装的是当前源码目录，且 `vendor/` 完整。检查使用的 profile、插件启用状态，重启后查看版本和日志。
- **章节读不出来**：先核对官网是否可见该正文。App 能阅读不代表网页也能读取；锁定或字体解析问题属于已说明的边界。
- **请求失败或限流**：按返回的等待时间再操作。公开请求遇到网络中断或 502/503/504 最多重试一次，账号请求不自动重试。
- **分类搜索或书评失败**：MCP、Skill 使用的匿名示例设备可能失效，可配置配套的 `FANQIE_DEVICE_ID` 与 `FANQIE_INSTALL_ID`。这与本人扫码会话是两条独立链路。
- **划线分页出现空页**：账号查询应以 `has_more=false` 为结束条件，上游分页还会计入书签等记录。缺少云端进度也不能推断从未阅读，返回的进度值不能直接当作百分比。
