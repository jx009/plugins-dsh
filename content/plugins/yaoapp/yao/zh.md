## yao 是做什么的？

yao 是一个以产品集成形式提供跨设备智能体管理能力的 DSH 插件生态项目，对应的产品是 Yao Agents。它已接入 DeepSeek Harness，面向需要在自有设备上运行智能体、集中管理工作区与任务的开发者。用户可以从桌面端、Android、浏览器或 API 访问工作。

如果你在寻找 DeepSeek Harness 插件，需要先明确其交付形式：现有 README 描述的是产品内置集成，没有提供独立 npm 扩展的安装方式。每增加一台机器，智能体就多一个工作节点，相关工作仍可集中管理，适合把多台电脑上的任务放在同一环境中组织。

## yao 核心功能

- **跨设备运行**：智能体在用户自己的设备上执行，新增机器可以成为工作节点。内置 Harness 可通过桌面应用、Android 和浏览器使用，其中移动客户端标注为 Beta。
- **隔离工作区**：不同工作区保持隔离，并可跨电脑管理。工作成果逐渐积累为文档，构成知识库；智能体在执行过程中可以从任意节点读取需要的材料。
- **任务看板**：在对话中提出需求后，工作可以成为看板任务。持续交流和执行可逐步形成适合该类工作的智能体，任务智能体还可连接应用或分享给他人。
- **Open API**：专家智能体和任务智能体能够接入已有应用与业务流程。接口支持 SSE 和 WebSocket，可作为开发者选择集成方式的依据。
- **Jev 类型化决策**：产品还提供 TypeSafe AI 的 System One 模型 Jev。它输出带置信度的类型化决策，适合了解结构化决策能力的用户进一步查阅。

## 怎么安装和使用 yao？

现有 README 没有 DSH 安装命令，仓库资料也未确认 npm 包名，因此没有可直接复制的插件安装指令。请从官方客户端或部署文档入口开始。

1. 选择访问端。桌面版下载地址为 `https://yaoagents.com/download`；Android Beta 下载地址为 `https://yaoagents.com/download/yaoagents`。产品也支持浏览器访问。
2. 查看 `https://yaoagents.com/docs`，按文档完成对应的安装或自托管部署。当前摘录未列出配置文件位置、服务端依赖和设备添加步骤，这些细节应以部署文档为准。
3. 在所选客户端中使用已集成的 Harness，并按工作内容组织隔离工作区。需要增加执行设备时，按照产品文档完成机器接入。
4. 在对话中描述任务需求，再通过看板跟踪工作。任务进行时继续补充上下文，使后续执行围绕同一类工作展开。
5. 如需接入自己的应用，查阅 Open API 文档，再选择 SSE 或 WebSocket。摘录未提供接口路径与认证配置，不能据此直接拼接调用示例。

## yao 报错怎么排查？

README 明确提示的风险是版本升级：Yao 2.0 不向后兼容 1.0。自行部署或维护 fork 的用户应先阅读 `BREAKING.md`，再进行更新。项目目前聚焦 v2.0 开发，相关工作可在 `YaoApp/tai-golang` 中查看。

其他故障可先做通用检查：记录产品和 Harness 版本，重启受影响的应用，再查看可用日志。如果使用场景另有 DSH profile 或插件配置，也应确认启动的是预期 profile，相关插件已经启用。这些属于诊断步骤，并非 README 针对某个具体报错给出的修复方案。

当前摘录没有错误码、完整平台兼容表或客户端专用恢复流程。排查时应结合实际症状和日志定位对应文档，避免仅凭版本号或客户端名称推断故障原因。
