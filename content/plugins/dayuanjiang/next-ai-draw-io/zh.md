## next-ai-draw-io 是做什么的？

next-ai-draw-io 根据自然语言请求在 draw.io 画布上生成图表，可用于架构图、流程图、时序图等。也可以上传截图、草图或文档，让 AI 根据这些材料绘图。

项目提供网页版、适用于 Windows、macOS 和 Linux 的桌面应用，以及向智能体提供绘图能力的 MCP 服务。

## 核心功能

- 使用内置的 AWS、Azure、GCP 和 Kubernetes 图标生成图表。
- 将手动画布编辑与对话修改结合，可将修改范围限定为选中的形状。
- 在画布上逐步显示 AI 修改，并高亮发生变化的形状。
- 以带缩略图的版本记录查看 AI 变更，支持对比、恢复和撤销。
- 支持多页面图表，可导出 `.drawio`、`.png`、`.svg` 或 `.drawio.svg` 文件。

应用支持 25 家模型服务商及 OpenAI 兼容端点预设，提供深色模式，以及英语、简体中文、繁体中文和日语界面。

## 怎么使用 next-ai-draw-io

打开在线演示，或从仓库的 Releases 页面下载桌面安装包。描述需要的图表，或上传参考材料；随后通过对话或画布操作调整内容，最后按所需格式导出。

如需让智能体调用，可在 MCP 客户端中将启动命令设为 `npx`，参数设为 `@next-ai-drawio/mcp-server@latest`。README 列举了 Claude Desktop、Cursor 和 VS Code 等客户端。所提供的片段没有 DSH 专用安装命令。
