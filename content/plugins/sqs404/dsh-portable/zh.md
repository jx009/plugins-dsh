## dsh-portable 是做什么的？

`dsh-portable` 是一个面向 64 位 Windows 10 和 11 的 DSH 免安装分发工具。它将官方 DeepSeek Harness npm 包、Node.js 运行时和图形启动器打包到同一个目录。它不是装进现有环境的 DSH 插件，也不是官方发布的 Windows 便携版；它解决的是不用另外安装运行时，就能解压启动本地 Web 界面的问题。

如果只是想在电脑上试用网页界面，直接下载发布压缩包即可，不必从源码构建。官方将 DeepSeek Harness 标注为开发者预览版，版本更新可能带来不兼容变更。智能体也可能修改文件或执行命令，初次体验时建议从测试目录开始。

## dsh-portable 核心功能

- **双击打开网页**：启动器使用随包提供的 Node.js 运行本地服务，并自动打开浏览器。运行成品不需要单独安装 Node.js 或开发工具。
- **数据留在便携目录**：启动器通过 `DSH_HOME` 将数据根目录指向旁边的 `data`，不读写系统用户目录。首次运行会在 `data\profiles\web` 初始化 Web 配置，这一步无需联网。
- **整目录复制**：发布包中的 npm 依赖以实际文件和目录分发，不依赖符号链接或目录联接。换电脑时应复制整个便携文件夹，而不是只带走启动器。
- **自定义端口与启动日志**：默认端口为 `3081`，可以通过同目录的 `port.txt` 修改。运行输出会写入 `dsh-console.log`，方便核对服务有没有启动。

## 怎么安装和使用 dsh-portable？

这个项目没有 DSH 插件安装命令。正常使用从下载成品开始，仓库里的 PowerShell 脚本是给需要自行构建的人用的。

1. 打开 `sqs404/dsh-portable` 仓库的 Releases，下载最新发布压缩包。确认电脑运行的是 64 位 Windows 10 或 11，再将压缩包完整解压到本地。解压路径可以包含中文。
2. 双击 `启动 DeepSeek Harness.exe`，等待浏览器自动打开本地页面。默认服务地址使用 `127.0.0.1:3081`，首次进入时以启动器实际打开的地址为准。
3. 按网页提示配置模型服务。使用 DeepSeek 服务时，按提示填写 DeepSeek API Key。能打开本地界面不代表模型已经连通，模型调用和联网搜索都需要网络。
4. 如果要改端口，在启动器所在目录创建 `port.txt`，写入所需的端口号，然后关闭运行中的命令行窗口并重新启动。平时用完后，关闭该窗口即可停止服务。

## dsh-portable 报错怎么排查？

- **直接访问本地页返回 401**：从 `0.1.2-alpha` 起，Web 界面使用一次性令牌进行认证。手动输入不带令牌的地址可能被拒绝。重新通过启动器打开页面，让浏览器完成认证并保存会话。
- **双击后网页没有打开**：确认系统版本符合要求、压缩包已完整解压，并检查是否修改过 `port.txt`。关闭旧窗口后再启动，查看 `dsh-console.log`，核对日志里有没有 Web 服务的启动输出以及实际使用的端口。
- **网页能打开，但模型没有响应**：先按页面提示复查模型服务配置，再确认网络是否可用。首次初始化可以离线完成，但这并不意味着模型 API 也能离线调用。
