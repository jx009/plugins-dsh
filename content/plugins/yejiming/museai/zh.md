## MuseAI 是做什么的？

MuseAI 是一个通过独立客户端接入角色互动的 DSH 插件，其主应用提供本地 AI 伴侣、文字冒险和穿书体验。它面向希望持续经营角色关系的用户，将人物设定、故事背景、共同经历与记忆联系起来，让下一次互动能够延续此前的故事。

主仓库介绍的是桌面应用，并将 DeepSeek Harness 插件用户引导到 `yejiming/dsh-museai-tavern`。以下功能和设置路径以主应用 README 为依据；现有资料没有说明客户端是否覆盖全部功能，也没有给出其配置界面。

## MuseAI 核心功能

- **世界书与角色卡**：世界书记录时代、地理、势力、规则与冲突；角色卡记录性格、说话方式、关系和底线。可以手动创建，也能从小说或大纲提取，并在不同互动模式中复用。
- **AI 伴侣聊天**：选择一个角色开展持续对话，回应会参考人设和过往记忆。对话结束后可归档关键事件，更新人物关系与角色资料。
- **文字冒险**：为一个世界书绑定多个角色，由 AI 担任故事主持人。通过语言、行为和剧情指令推进场景，共同经历可转为角色记忆。
- **穿书互动**：将大纲、世界书和角色卡装配成故事素材，选择入场点与身份后参与剧情。支持保存进度，之后继续当前故事。
- **羁绊档案**：按角色查看关系概览、关键事件时间线、聊天和冒险足迹。主应用还提供 Markdown 编辑、大纲评估与反向大纲等素材整理工具。

## 怎么安装和使用 MuseAI？

当前 README 没有 DSH 安装命令，也没有可确认的 npm 包名，因此无法据此生成安装命令。插件安装请查看 `https://github.com/yejiming/dsh-museai-tavern` 的说明。

桌面应用可按以下流程开始使用：

1. 前往 `https://github.com/yejiming/MuseAI/releases`，下载 `.dmg` 或 `.exe` 安装包，安装并启动。
2. 打开「设置」，填写 API Key、API 地址和模型名，再点击「测试连接」。支持 OpenAI、Anthropic 和兼容 OpenAI 格式的服务；不同模块可分别选择模型与参数。
3. 在「背景设定」建立世界书和角色卡，先填写关键背景与人物特征，再到「伴侣对话」选择角色聊天。
4. 想跑团时，在「冒险」选择世界书和多个角色，输入开场剧情；想穿书时，先在「穿书素材」装配资料，再进入剧情选择入口与身份。
5. 聊天或冒险结束后归档记忆，到「羁绊」回顾关系变化。定期备份 `~/Documents/MuseAI/`，保留设定、会话和配置。

手机访问时，保持桌面应用运行，让手机与电脑连接同一 WiFi，再用浏览器打开电脑「设置」中显示的网址。数据仍保存在电脑上；主动调用模型时，相关上下文会发送给所配置的服务商。

## MuseAI 报错怎么排查？

- **连接测试失败**：检查 Key 是否漏字或带空格，API 地址是否完整，并确认网络可达、账户余额充足。
- **角色突然出戏**：确认绑定了正确的世界书与角色卡。长对话可尝试新建会话，或调整聊天 Agent 的最大上下文 Token、系统提示词与温度。
- **设定提取失败**：先重试；提取角色卡时，可手动提供角色姓名列表，帮助模型按名单输出。
- **封存记忆失败**：先重试；多次失败则进入「羁绊页设置」，把对应封存记忆 Agent 的温度设为 `0`。
- **反向大纲被截断**：在「大纲页设置」调高相关 Agent 的最大输出 Token，并把提示词中的字数要求写得更明确。
- **更新后功能不可用**：在「设置」恢复对应模块的默认系统提示词。若是 DSH 客户端未加载，可依次确认 profile、插件启用状态、版本和日志，再重启宿主。
