## tongflow 是做什么的？

tongflow 是一个面向多模态工作流的 DSH 插件生态项目，让人与智能体围绕可编辑、可重复运行的流程协作。仓库带有相关生态标签，但当前 README 介绍的是独立工作流平台，没有给出直接安装到宿主的步骤。寻找 DeepSeek Harness 插件的开发者，可以据此了解其能力与接入资料入口。

它解决的是生成过程难以检查、素材散落在不同工具中的问题。智能体产出工作流文件，人可以打开、修改并再次运行。营销内容、本地化、会议纪要和培训材料都是 README 列出的应用方向。

## tongflow 核心功能

- **多模态画布**：统一处理文本、图像、音频、视频、3D、文档和链接。每一步的输出留在画布上，便于从已有结果继续加工。
- **可复用的智能体流程**：智能体与人使用相同的工作流工具。生成的流程可以人工检查，也可以换一组素材重新运行或交给同事。
- **能力与模型分离**：先决定要完成的转换，再选择模型实现。README 列出六十多种能力和五十多个官方插件，覆盖商业 API、模型网关及开放模型。
- **运行记录**：保存工作流、步骤、插件、模型、输入输出和时间信息，方便追查某个结果的生成过程。
- **App Mode 表单**：将完成的流程转为表单，减少其他使用者操作画布的需求，也支持手机浏览器访问。

## 怎么安装和使用 tongflow？

当前资料没有可核实的 DSH 安装命令，npm 包名也未确认，因此本页不提供可复制的包安装指令。仓库名不能直接视为已发布的安装包名。

1. 选择使用方式。在线评估可访问 `app.tongflow.com`，使用浏览器或桌面应用；自托管支持源码和 Docker，具体部署步骤见 `docs/developers.md`。
2. 准备自己的模型 API 密钥和算力账户。在线服务的调用费用记入这些账户；现有 README 未说明密钥配置页面、文件位置或字段名称。
3. 从素材和目标结果开始，在画布上添加、转换、组合内容。先确定每一步需要的能力，再选择背后的模型实现。
4. 检查中间输出和运行记录，确认流程符合预期后，用新素材重复运行，或把可编辑的流程交给同事。
5. 需要表单入口时使用 App Mode；需要连接智能体或开发节点、插件时，继续查阅开发者指南。

在线服务定位为评估用途，免费期为七天，之后需要在产品内订阅。私有部署可按需求交付单点登录、角色权限、付费运行审批、审计导出和远程 MCP 服务，这些项目应在部署需求中单独确认。

## tongflow 报错怎么排查？

现有 README 没有错误码或专门的故障修复清单。先确定问题发生在在线评估、源码部署、Docker 环境，还是另行配置的宿主集成中，避免混用不同入口的处理步骤。

若已经配置 DSH 集成，可先确认当前 profile 名称、插件是否启用，再重启宿主。这些属于通用检查，不代表仓库已经提供对应的安装方案。

记录使用版本并检查可获得的日志。流程执行异常时，通过运行记录定位具体步骤、插件、模型和输入输出，再对照 `docs/developers.md` 中的部署与智能体连接说明检查。不要猜测安装包名、配置字段或 MCP 地址。
