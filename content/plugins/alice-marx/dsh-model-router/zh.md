## dsh-model-router 是做什么的？

dsh-model-router 是一个把任务整理成可审查的执行计划，并按需选择模型和工具的 DSH 插件。你可以在运行前比较方案，确认会用到哪些模型、工具、工作区和权限，再查看预计开销。运行后可以在同一处跟踪进度和结果。这是社区维护的 DeepSeek Harness 插件，各模型服务和命令行工具仍使用各自的账号和访问权限。

如果只想在标准界面里做模型路由、执行任务和查看用量，选纯路由版即可。如果还需要长期保留 Bot 对话、把任务交给其他 Bot，或为不同 Bot 分开管理文件，就选完整版。两个版本共享路由配置，同一个配置档只装其中一个。

## dsh-model-router 核心功能

- **按任务选择模型路由**：从任务模板开始，比较省钱、均衡和质量优先三种方案。可以采用一条路由、按依赖关系安排多个执行角色，也可以直接指定模型。
- **先审查再执行**：确认前检查模型、工具、工作区、权限和费用估算。启动后可查看进度与结果、取消任务，并在支持的情况下重试。
- **管理原生 CLI 工具**：检测已登记的工具，检查是否登录以及所选模式是否就绪，也可以打开交互式终端。订阅账号的调用次数和词元用量可单独查看，API 用量则可设置预算上限。
- **保留对话并委派任务**：完整版允许为每个 Bot 单独设置角色、模型、工作目录和权限。主 Bot 可按已保存的模型、工具、电脑和经费设置，挑选符合条件的执行 Bot。

## 怎么安装和使用 dsh-model-router？

1. 在目标配置档打开「插件 → 添加插件」。完整版填入 `@ljwei-stak/dsh-model-route-bot`；纯路由版填入 `@ljwei-stak/dsh-model-router`。添加后确认所选版本已启用。
2. 打开对应入口。纯路由版从标准界面的 `Model Router` 进入；完整版从 Bot 联系人和聊天界面开始。更换版本时，先在同一配置档移除原插件条目，再添加另一个包，保留数据目录和已配置的 Bot 主目录。
3. 完整版在「设置 → AI」中配置连接。添加 API 模型时，填写服务端点、对应凭据和模型容量；也可以按需要配置订阅账号或 CLI 聊天。保存后到目标 Bot 的「模型与工具」选择路线。若任务需要执行工具，在对应工具项中选定账号和执行模式，再保存授权。
4. 首次使用可从一个任务模板开始，挑选候选方案，核对工作区、权限和开销后再确认执行。任务结束后查看结果和用量记录，再决定下次是沿用当前路线，还是改用其他模型。

## dsh-model-router 报错怎么排查？

- **找不到插件入口**：确认当前打开的是安装时使用的配置档，插件已经启用，并且正在找所装版本的入口。如果仍未显示，重启 DSH，再核对插件版本和运行日志。
- **工具没有就绪**：先完成供应商登录并刷新检测，再检查所选工具的账号、模型和模式是否已保存。若界面提示托管执行入口需要修复，可在「配置和修复」中检查安装。
- **旧订阅账号无法继续使用**：如果旧记录提示重新授权，按界面指引完成登录，再为对应 Bot 选择新的模型路由。若问题出在聊天可用但任务无法执行，单独检查执行工具的授权。
