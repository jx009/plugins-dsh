## SkillCorpus 是做什么的？

SkillCorpus 是一个按任务检索智能体技能的 DSH 插件，将相关操作流程带入回答前的上下文。它面向需要复用任务步骤的开发者，减少逐次手动挑选技能的工作。底层开源流水线收集公共仓库中的 `SKILL.md`，经过安全与许可证筛选、质量评估，再匹配当前任务。

这款 DeepSeek Harness 插件属于更完整的语料、检索和评估项目。SkillHub 提供托管使用入口；仓库则提供构建技能层、修改检索行为和自行部署的代码。需要自定义来源或导出语料时，可以使用这些底层能力。

## SkillCorpus 核心功能

- **任务技能检索**：把相关流程放入智能体执行前的上下文。技能内容可以包含操作步骤、参考资料和可选的辅助脚本。
- **多源搜索与去重**：支持本地技能、EverMind SkillHub、ClawHub 和 skillhub.cn。候选经过过滤和去重，最终选择零到两个技能。
- **自动或按需调用**：项目提供每次查询自动检索，以及主智能体调用 `skill_search` 的方式。具体模式配置需查看宿主指南。
- **跨宿主共享技能库**：v0.4.0 引入 `~/.evermind-skillsearch/` 公共目录，并保留从目录检索到的技能。技能库变更在下一轮生效，无需重启。
- **语料筛选与自部署**：开发者可调整分类体系、质量和去重规则、导出结构及评估套件，也可自行部署已发布的检索模型。

## 怎么安装和使用 SkillCorpus？

当前 README 摘录没有提供 DSH 安装命令，也未确认 npm 包名，因此这里不生成安装指令。仓库指定的专用指南位于 `skillcorpus_plugin/engine-typescript/README.md`，应先打开该文件核对安装和配置步骤。

1. 按专用指南安装到目标环境。摘录没有给出配置文件位置或凭据要求，这些细节需要以该指南为准。
2. 确定要检索的技能来源。项目支持本地集合与外部目录，具体如何启用来源，应查看宿主侧设置说明。
3. 查看如何选择自动检索或按需调用，然后向智能体描述实际任务，让检索层按任务匹配流程知识。
4. 使用 v0.4.0 的共享库能力时，关注上述公共目录。目录检索得到的技能会保留，修改技能库后可在下一轮检查效果。
5. 需要自定义筛选、评估、语料导出或自部署时，再克隆仓库使用底层工具。单独使用托管入口无需克隆项目。

## SkillCorpus 报错怎么排查？

摘录没有列出具体错误码或 DSH 故障解法，可以先做通用检查：确认当前 profile 名称与安装目标一致，确认插件已启用，再对照专用指南查看版本要求。检查可用日志，区分插件未加载与技能检索异常。

如果宿主中没有出现集成，可重启后再次检查。但对于 v0.4.0 的共享技能库修改，应先尝试下一轮对话，因为 README 明确说明此类变更无需重启。最终检索允许返回零个技能，因此空结果本身不能直接认定为故障。

导出或复用语料时，还应单独核对技能许可证。仓库核心代码采用 Apache-2.0，`match/`、`evaluate/` 和 `lifecycle/` 使用 MIT；各技能仍保留上游许可证，不能直接按仓库许可证统一处理。
