## planning-with-files 是做什么的？

planning-with-files 是一个将任务计划持久保存到 Markdown 文件的 DSH 插件。它面向执行长时间编码任务的开发者，将计划、发现和进度保留在对话窗口之外，减少上下文丢失后重新梳理任务的工作。README 明确列出了原生 DeepSeek Harness 插件支持。

它围绕 `task_plan.md`、`findings.md` 和 `progress.md` 三个文件组织任务信息。执行 `/clear`、发生上下文压缩或程序崩溃后，磁盘上的记录仍可作为恢复依据。启用的生命周期钩子逐轮注入选定的项目计划上下文，帮助智能体在长任务中持续参考已有记录。

恢复范围也有明确边界：自动恢复只读取项目文件。如果需要读取同一项目的本地智能体会话记录，进行汇总计数或有限回放，则必须显式启用 catchup 模式。使用时应区分计划文件恢复与历史会话追溯，避免把两者理解成同一种行为。

## planning-with-files 核心功能

- **Markdown 持久化计划**：三个命名文件分别承载计划、发现和进度。任务信息保存在磁盘上，可跨越单次对话上下文继续使用。
- **会话恢复**：项目说明支持在清空上下文、压缩及崩溃后保留计划。恢复所需的信息来自已经保存的项目记录。
- **逐轮上下文注入**：启用的生命周期钩子会重新提供选定的计划内容，帮助长时间运行的任务持续参考项目上下文。
- **显式会话追溯**：自动恢复限定为读取项目文件；读取同项目的本地会话记录需要明确选择 catchup 模式。
- **多智能体支持**：项目通过 Agent Skills 标准覆盖超过 60 种智能体，同时为多个宿主提供原生插件集成。

## 怎么安装和使用 planning-with-files？

提供的 README 片段没有 DSH 安装命令，仓库信息也没有确认 npm 包名，因此这里不生成可执行的安装命令。README 指向仓库内的 `docs/installation.md`，应先查看其中对应宿主的完整安装说明。

1. 在完整安装文档中查找 DeepSeek Harness 集成，核对包标识、安装步骤及配置要求后再操作。
2. 安装完成后，确认插件已在准备使用的 DSH profile 中启用。当前片段未提供配置文件位置或激活命令，具体设置以完整文档为准。
3. 开始任务时围绕三个项目文件整理信息：用 `task_plan.md` 查看计划，用 `findings.md` 保留发现，用 `progress.md` 跟踪进度。
4. 随工作推进保持文件内容与任务状态一致。上下文丢失后，自动恢复依赖的是这些磁盘记录。
5. 继续任务时先核对项目计划是否完整；若需要追溯本地会话，再查阅显式 catchup 模式的用法。当前片段没有给出调用语法。

## planning-with-files 报错怎么排查？

当前 README 片段未列出 DSH 专用错误码或具体修复方案。计划未出现、上下文没有恢复时，可先做以下通用检查：

- 确认打开的是目标项目，并检查三个计划文件是否存在、是否包含预期记录。
- 核对当前 profile 名称，以及插件是否已在该配置中启用。
- 重启 DSH；若问题持续，检查宿主与插件版本，并查看可用日志。
- 如果缺少历史对话细节，先核对恢复范围：自动恢复读取项目文件，会话记录访问需要显式 catchup。

进一步排查时，记录问题发生在 `/clear`、上下文压缩还是崩溃之后，并保留 profile、版本及相关日志，便于对照完整安装文档确认宿主配置。
