## SAG 是做什么的？

SAG 是面向个人与智能体的本地优先知识库，通过 MCP 和 API 提供文档检索能力。对于寻找 DSH 插件来补充知识检索的开发者，它是可评估的接入对象；现有 README 没有说明它是原生 DeepSeek Harness 插件，也未提供专用连接步骤。它解决的是资料分散、答案难以核对出处的问题。

导入文件或网页后，应用会解析文档、分块、生成向量，并抽取事件与实体。用户可以搜索知识、查看关联，再围绕选定来源进行多轮问答。产品定位是单用户应用，默认使用 SQLite 与 LanceDB，无须外部数据库。

## SAG 核心功能

- **事件实体索引**：每个文本块对应一个语义完整的事件，以及多个用于索引的实体。查询时通过 SQL 连接共享实体的事件，形成与当前问题有关的动态超边。
- **多种检索模式**：快速模式使用 `vector` 或 `multi_es_fast`，精确模式使用 `multi`，可选的 JEV 重排使用 `multi_jev`。支持跨来源搜索，也能限定来源范围。
- **原文溯源与引用问答**：检索结果关联到原始文本块，便于检查上下文。智能体围绕选定来源回答问题，并给出可点击引用。
- **知识图谱查看**：可以检查事件、实体及其关联。新增文本块只需加入自身记录和关联，无须重建全局图谱。
- **MCP 与 API 接入**：提供自托管 REST/OpenAPI、OpenAI 兼容聊天接口及 Python 包 `zleap-sag`。这些是项目公开的集成方式，具体 DSH 配置仍需核对完整文档。

## 怎么安装和使用 SAG？

提供的 README 没有 DSH 安装命令，也没有确认 npm 包名，因此这里不生成插件安装指令。Docker 快速开始部分已被截断，不能据此补写可执行部署命令。

1. 从仓库的 GitHub Releases 选择桌面安装包。macOS 15 及以上的 Apple Silicon 设备使用 `SAG-*-mac-arm64.dmg`；Windows 10/11 x64 使用 `SAG-Setup-*-win-x64.exe`。
2. 安装并打开工作区。桌面版包含本地后端，不需要另外准备 Python、Node.js 或数据库。
3. 上传文档或添加网页来源，由应用完成解析、分块、向量化与事件实体抽取。
4. 选择检索范围和模式，打开结果对应的原始片段核对内容；需要综合回答时，使用带引用的智能体聊天。
5. 如需供外部智能体调用，按完整集成文档选择 MCP 或 API。当前材料未给出连接地址、认证字段、模型设置位置或 DSH 配置文件路径。

自托管用户需准备 Docker Desktop，或带 Compose v2 的 Docker Engine，其余部署步骤应以完整指南为准。

## SAG 报错怎么排查？

Windows 安装包目前未签名，系统可能提示发布者未知；README 已说明这一情况。发布文件提供 `SHA256SUMS.txt` 校验信息。两个桌面平台的应用内更新都需要分别确认下载和安装。

若出现旧知识数据不兼容提示，应先阅读备份与新工作区确认说明。确认前旧数据保持不变；账号和模型设置会保留，但旧知识库、文档、智能体、会话及相关任务不会出现在新工作区，需要重新上传资料，备份仍可用于手动恢复。

若自行配置的 DSH 接入未显示，可先确认当前 profile、相关集成是否启用，再重启并检查版本与日志。这些属于通用检查步骤，当前 README 未提供专门的连接错误码或修复命令。
