## dsh-Go 是做什么的？

dsh-Go 是一个支持 DSH 插件界面的 Android 客户端，让开发者在手机上运行引擎，或连接电脑继续处理任务。它是基于 DeepSeek Harness 的社区非官方项目，提供聊天、本机环境和远程访问能力，并非已确认可通过 npm 安装的扩展包。

手机运行的是代理引擎，模型请求仍发往你配置的提供方。本机模式不代表离线推理，也不保证数据留在设备内；需要在移动端查看对话、处理工具审批或使用适配插件时，可以考虑这一入口。

## dsh-Go 核心功能

- **本机 Linux 环境**：在应用内安装 Ubuntu、Node.js 和引擎，无需 Root，也不用另装 Termux。
- **SSH 远程连接**：支持连接电脑或服务器，也可使用 DSHarness Remote；仅连接远程主机时，无须安装手机本机环境。
- **聊天与插件界面**：支持模型切换、图片、语音输入和工具审批。适配的 DeepSeek Harness 插件可展示原生工具卡、表单和面板，仓库提供 SDK 与示例。
- **手机操控**：授权后，本机引擎可读取屏幕、点按和输入，用户可随时停止。敏感操作默认保留保护，不建议随意解除限制。
- **对话分享与回放**：可制作回复分享卡，通过端到端加密链接让接收者在浏览器回放。分享前应检查预览，接收者仍能保存内容。

界面还适配横屏与平板，支持中英文切换，以及主题、图标和桌宠设置。

## 怎么安装和使用 dsh-Go？

现有资料未确认 npm 包名，也未提供 DSH 安装命令，因此应下载 APK，不要把仓库名直接套入插件安装模板。

1. 从 GitHub Releases 获取安装包：`https://github.com/ccch1mneyyy/dsh-Go/releases`。系统要求 Android 8.0 及以上，常见 64 位手机选 arm64；x86_64 设备或模拟器在发布说明的其他版本下载区找 x64 包，没有 32 位 ARM 构建。
2. 按系统提示允许对应安装来源，完成 APK 侧载；README 未提供 Google Play 安装流程。
3. 首次启动选择安装本机环境，或连接远程主机，再按所选方式配置。
4. 为目标主机设置模型和凭据后开始对话。部分远程渠道需在主机侧配置，不能默认全部在手机端完成。
5. 如需手机操控，按提示开启无障碍等权限。该功能面向正常模式下的本机引擎；不打扰模式另需 Android 14 及以上，以及 Shizuku 或自连 ADB。

语言可在设置中切换。匿名使用统计默认开启，可在首次引导或“设置 → 隐私与分享”关闭；操控任务所需的屏幕文字，以及支持看图模型使用的截图，可能发送给模型提供方。

## dsh-Go 报错怎么排查？

- **无法覆盖安装**：先确认是否装过签名不同的早期测试包。此时需先卸载旧版，但卸载会清空对话、Linux 环境和设置，操作前先保存重要数据。
- **远程功能缺失**：先确认连接方式。DSHarness Remote 仅支持图片附件，不能打开应用内网页版，插件管理只有开关，也不支持 DS Bot 与对话日志导出。
- **本机启动异常**：默认使用 PRoot 兼容启动。若自行开启了开发者选项中的直接启动，应查阅项目常见问题中的兼容性与回退说明，不要默认所有设备都适用。
- **其他配置问题**：检查目标主机、模型凭据、版本及可用日志。若涉及主机侧插件，再核对 profile 名和启用状态，随后重启对应引擎。
