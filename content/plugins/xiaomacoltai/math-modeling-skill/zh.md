## math-modeling-skill 是做什么的？

math-modeling-skill 是一个把建模分析、代码实现和论文撰写串起来的 DSH 插件。它以桌面端智能体预设的形式提供任务看板、阶段质检和交付检查，适合 CUMCM、MCM/ICM 等数学建模竞赛，也能用于一般建模项目。你可以从题目和附件开始跑完整流程，也可以把现有模型或实验结果交给预设，只补做求解、绘图或论文撰写。

## math-modeling-skill 核心功能

- **建模分析与算法选型**：先检查题目和附件，拆分子问题，再根据算法索引选择优化、预测、评价、图论或机器学习等方法。分析阶段会交付题目分析报告和术语表，供后续实现核对。
- **双语言求解与科研绘图**：用 Python 或 MATLAB 实现模型，按实际用到的功能检查依赖。除了结果表，还可生成原始数据图、求解过程图、结果图和总体建模流程图，支持导出 SVG 与 300 DPI PNG。
- **可复现记录与阶段质检**：复现清单记录随机种子、输入文件哈希、环境版本、关键参数和复现命令。五个固定质检节点分布在三个阶段中，例如先确认最小结果能跑通，再做全量计算。
- **双引擎文献检索**：用 OpenAlex 和 AnySearch 并行搜索论文，再按 DOI 或题名交叉核验。正式检索默认启用两个引擎，单引擎模式用于诊断。
- **论文与官方模板**：依据实际运行结果组织论证，默认生成 `完整论文.docx`，Word 公式可保留为原生 OMML。需要 LaTeX 源码项目和实际编译的 PDF 时，应在会话中明确提出。

## 怎么安装和使用 math-modeling-skill？

仓库没有提供 DSH 安装命令，也未确认 npm 包名。这个 DeepSeek Harness 插件通过复制桌面预设安装，不用套用包管理安装命令。

1. 下载或克隆仓库，把 `dsh-plugin/math-modeling-agent/` 整个目录复制到 `<dsh-home>\.agent-presets\`。Windows 默认位置是 `C:\Users\<用户名>\AppData\Roaming\dsh-desktop\dsh-home\.agent-presets`。也可以把 `dsh-plugin/README.md` 里的安装提示词交给桌面端智能体处理。
2. 新建会话，选择「数学建模 Workbench」。预设自带知识库，可通过 `skill` 工具加载，无需另行配置外部仓库路径。可用 `mm_todo` 查看待办，用 `mm_state` 查看当前阶段。
3. 在会话中说明题目和附件的位置、要跑的阶段、编程语言及目标交付格式。如果只想先看思路，可以输入 `只做建模分析，交付题目分析报告和术语表`。题目和附件保持只读，代码、图表和论文写入项目目录；需要修改模板时，先复制到该目录。

生成的论文仅供参考。准备提交前，应以目标竞赛当届的官方规则和模板为准，核对摘要、页数、编号和文件格式。

## math-modeling-skill 报错怎么排查？

- **新会话找不到预设**：确认复制的是完整目录，并检查它是否位于当前桌面端使用的 `dsh-home` 下。核对当前配置档和会话所选预设，必要时重启 DSH；仍不显示时，查看客户端版本和日志。
- **代码无法运行**：先按当前模型实际用到的数据处理、绘图或优化功能检查 Python 或 MATLAB 环境。如果问题出在公式、约束或参数无法实现，应把实际报错带回建模阶段修正，再继续求解。
- **质检未通过**：从被阻断的阶段入手。比如论文结论缺少实际结果或图表支撑，就先回到对应阶段补齐证据，再重新质检，而不是跳过检查直接生成终稿。
