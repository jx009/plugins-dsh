## opskat 是做什么的？

opskat 是一个整合远程连接、数据库工具和可选 AI 操作的桌面运维工作台。它面向需要管理多类基础设施的开发者和运维人员，把终端、查询编辑器、远程桌面与服务管理放在同一个应用中。即使不配置模型，也能使用已有的手动运维功能。

对于正在寻找 DSH 插件的用户，需要先确认交付形式：仓库带有 `dsh-plugins` topic，但所提供的 README 介绍的是独立桌面应用，没有说明直接接入方式。因此，尚不能把它描述成可通过命令安装的 DeepSeek Harness 插件，以下按已记录的桌面使用流程介绍。

## opskat 核心功能

- **SSH 与文件管理**：提供分屏终端、SFTP 文件浏览、跳板机链、端口转发和 SOCKS 代理。支持按树形结构组织不同类型的资产。
- **内置远程桌面**：在应用标签页内使用 RDP 和 VNC，无需单独的桥接服务。两者支持文本剪贴板同步，前者还支持直接传输文件剪贴板内容。
- **数据库与 Redis**：为 MySQL、PostgreSQL、SQL Server 和 SQLite 提供查询编辑与数据浏览。另有键浏览和命令执行功能，以及 MongoDB 集合浏览与查询。
- **Kafka 与集群操作**：可管理主题、消息、消费组、ACL、Schema Registry 和 Kafka Connect。AI 示例还包括通过 kubectl 检查 Kubernetes 节点与 Pod 状态。
- **对象存储与 AI 工具**：支持浏览 S3 兼容存储、上传下载对象和生成预签名 URL。智能体可调用已注册工具执行支持的任务，策略、审批与审计行为取决于具体操作路径。

## 怎么安装和使用 opskat？

所给 README 没有 DSH 安装命令，也没有已确认的 npm 包名，因此不能生成插件安装命令。项目记录的安装方式是下载桌面发行版。

1. 从仓库 Releases 页面选择 Windows、macOS 或 Linux 构建并运行。使用预编译版本不需要准备 Go 或 Node 开发环境。
2. 添加服务器、数据库或对象存储等资产；已有连接可从 SSH config、Tabby、WindTerm、.rdp 文件或支持的 Excel 模板导入。
3. 打开对应资产，先完成一次具体操作，例如启动终端、执行查询、浏览键或查看存储桶。这也是开始使用智能体前确认操作对象的直接方式。
4. 需要经过中间节点时，为资产配置有序代理链。可组合已有 SSH 资产、SOCKS5，以及使用 URL、token 和 timeout 参数的 HTTP 脚本隧道。
5. 如需自然语言操作，在应用中配置兼容 OpenAI 或 Anthropic 的提供商并填写自己的密钥，再提出获取日志、查看消费组积压等受支持的请求。当前摘录未给出配置文件路径或具体菜单名称。

## opskat 报错怎么排查？

当前摘录没有专门的错误码表或故障处理章节。遇到问题时，可先确认应用版本、查看可用日志，并记录失败的资产类型与操作步骤，便于进一步定位。

代理配置有明确的优先级规则：保存新的链后，`proxy_chain` 会优先于旧的单层 SSH 隧道或 SOCKS5 设置。若实际连接路径与预期不同，应检查保存后的链。另需区分本地 SQLite 与远程 SQLite VFS，后者通过所选 SSH 资产访问文件，并使用该资产的代理链。

如果你同时在检查 DSH 环境，可确认当前 profile 名、目标插件是否启用，并重启后查看版本与日志。这些属于通用环境检查，不能据此判断桌面应用已经作为插件接入。
