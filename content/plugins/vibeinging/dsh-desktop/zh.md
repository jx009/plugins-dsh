## dsh-desktop 是做什么的？

dsh-desktop 是一个集成官方 DSH Web 和社区 DSH 插件的桌面工作台。它以社区维护的桌面发行版提供，不是装进现有环境的单个 DeepSeek Harness 插件。桌面客户端负责窗口、原生文件选择、更新与恢复；对话、工具审批、设置和历史仍由官方运行时管理。

如果你想在同一个窗口里和智能体讨论改动、查看项目文件，再用终端核对结果，可以把它作为本地项目的入口。会话与插件状态都归当前的 DSH Profile 管理，不需要为桌面端维护另一份插件列表。新建 Profile 时，应用会用随包提供的固定版本离线初始化默认组件；正常启动不会覆盖已有配置。

## dsh-desktop 核心功能

- **官方会话**：主窗口直接使用官方 Web 界面。对话、排队消息、工具审批和历史回放都留在原有会话流程里，无须切换到另一套聊天页面。
- **Better Sidebar 侧栏**：从文件树查看项目，在侧栏编辑代码或 Markdown，也可以打开 Git、终端和网页标签页。在输入框添加文件或文件夹，就能把相关材料带进当前对话。
- **插件市场**：在官方设置页查看插件的来源、版本、兼容性和权限，并按需安装、更新、停用或卸载。设置页和命令行操作的是同一个 Profile。
- **Git Worktree 与任务看板**：可以从当前会话的工作目录创建隔离的工作区，并为新工作区建立官方会话。任务看板、项目工具和 Office 成果等能力由独立组件提供，可以按需取舍。
- **手机远程**：在侧栏登录并启用当前电脑后，可从 Android、浏览器或另一台桌面客户端继续同一个工作区和会话。桌面端只发起出站连接，不开放公网监听端口。

## 怎么安装和使用 dsh-desktop？

桌面应用没有对应的 DSH 安装命令。请到 `vibeinging/dsh-desktop` 仓库的 Releases 页面下载客户端，不要把仓库名当作 npm 包名传给 `dsh plugin`。

1. 选择与系统和处理器匹配的安装包。Apple Silicon Mac 下载 `.dmg` 后将应用拖入“应用程序”；Windows x64 以当前发布页提供的 `.exe` 为准，运行后选择安装范围和客户端目录。
2. 打开应用，选择一个工作目录或直接创建会话。模型凭据由 DSH 设置与本地环境管理；需要配置模型时，从应用中的官方设置入手。
3. 在侧栏打开文件、Git 或终端；要在对话里引用本地材料，可通过输入框添加文件或文件夹。
4. 需要扩展能力时，打开“设置 → 插件市场”。安装前核对兼容性、权限和上游说明；能在市场搜到不代表该插件已经过桌面项目审查，也不代表它随客户端内置。

## dsh-desktop 报错怎么排查？

- **首次启动受阻**：先核对安装包是否匹配系统和处理器。遇到 macOS Gatekeeper、Windows SmartScreen 或 API Key 问题，可查项目官网的首跑常见问题。
- **插件装了却没出现**：检查桌面端与命令行是否使用同一个 Profile，再到设置页确认插件已启用。重启应用后仍无效，就核对客户端、运行时和插件版本，并查看日志。
- **启动后进入恢复页**：Profile 或客户端出错时，应用会进入恢复页并保留原 Profile。先查看恢复页提示，再结合版本和日志判断问题出在哪里；更换客户端安装目录不会迁移 Profile 数据。
