## OpenBitFun 是做什么的？

OpenBitFun 是一个用于编程与日常任务的开源桌面智能体工作台。它由 Rust 编写的运行时管理会话、上下文和工具执行。你可以用它做代码审查，也可以让它处理需要拆分步骤的工作，或为重复操作制作专用界面。

如果你是搜 DSH 插件来到这里，需要区分仓库标签和安装说明：现有资料确认了桌面客户端及其功能，但没有给出 DeepSeek Harness 内的安装方式。下文的配置步骤适用于桌面版。

## OpenBitFun 核心功能

- **四种工作模式**：`Minimal` 适合目标清楚、需要快速反馈的任务；`Standard` 适合要先规划再执行和检查的多步骤任务。复杂任务可用 `Ultimate` 分派工作并汇总结果，想制作应用或调整工作台则选 `Creative`。
- **跨设备远程控制**：桌面端切换到另一台已连接的电脑时，会显示那台设备的会话、文件和任务状态。手机或浏览器可以发送指令、查看进度和响应审批；断开控制端后，任务仍在选定的主机上运行。
- **持久会话与中断恢复**：运行时保存会话状态，并提供长期记忆和中断恢复能力。较长任务还可以利用上下文压缩和缓存复用，减少重复处理上下文的开销。
- **Mini Apps**：让智能体为具体需求生成专用界面，比如把几项常用操作集中到一张表单里。应用附带独立的智能体对话，用起来发现不顺手的地方，可以直接在对话里提出修改。
- **角色与工具配置**：为专用智能体选择模型、定义角色，再按任务配工具。`MCP` 用来接入外部工具，`Skills` 用来复用流程，`Hooks` 则用于调整任务的运行方式。

## 怎么安装和使用 OpenBitFun？

当前没有可核实的 DSH 安装命令或 npm 包名，不要用仓库名代替包名执行安装。要使用 README 介绍的桌面能力，可按以下步骤开始：

1. 前往项目官网的桌面下载页，选择 `Windows`、`macOS` 或 `Linux` 对应的版本。需要手机端时，到仓库的移动端发布页获取客户端；也可以用浏览器控制。
2. 在桌面端按任务选择工作模式。第一次可以用 `Minimal` 提出一个目标明确的小任务，查看结果并补充反馈。需要让智能体承担固定职责时，再到智能体管理功能中选择模型、定义角色并配置所需工具。
3. 要远程控制另一台电脑，先让参与连接的设备登录同一个账号。默认使用官方 `Relay`，无需自行部署服务器；可用的登录方式包括 `GitHub` 和电子邮件验证码，具体以客户端支持为准。
4. 在桌面端选中目标设备后，确认当前看到的是那台设备的会话和任务。再从手机或浏览器查看进度或处理审批；退出控制界面不等于停止主机上的任务。

## OpenBitFun 报错怎么排查？

- **连不上设备**：先核对两端是否登录同一账号，以及提供会话和文件的那台电脑是否在线。数据按需从所属设备读取，控制端能打开不代表主机已连接。
- **局域网登录失败**：同网连接不是离线模式，登录仍需要访问在线身份服务。若用的是私有 `Relay`，还要核对客户端构建是否与部署匹配。
- **DSH 中找不到入口**：先确认你安装的是桌面版还是已有明确来源的插件版本。若确实装过后者，再核对当前 `profile` 和启用状态，重启 DSH 后查看版本与启动日志；桌面安装本身不能证明插件已加载。
