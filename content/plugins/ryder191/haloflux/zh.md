## haloflux 是做什么的？

haloflux 是为社区 DSH 插件提供视觉基础的科幻光环可视化项目。它用原生 Canvas 绘制编织光场、旋转数据面板和外扩光束；独立维护的社区集成则把画面变成随当前智能体会话变化的背景，适合希望为开发会话增加动态视觉的用户。

需要区分上游作品与 DeepSeek Harness 插件：Ryder191/haloflux 提供浏览器和壁纸版本；README 列出的 Ke-wood/dsh-haloflux 负责会话联动及设置页。另有 Michael-ZAG 维护的社区改进版，基于 v0.7.1 调整 HUD 布局并改善稳定性。

项目仅限非商业使用，可用于个人学习、兴趣项目和私人娱乐。发布截图或录屏时，需在帖文标题、正文或描述中注明来源仓库，不能仅放在评论区；商业用途不在许可范围内。

## haloflux 核心功能

- **节拍驱动光环**：不均匀时钟控制急停、冲刺和漂移，配合 12 种微型数据块与五层外圈光束形成画面。
- **实时参数控制**：浏览器控制台提供 56 项参数，可调整节拍、转速、辉光和景深；自动运镜包含七个镜头。
- **JSON 设置迁移**：支持导入导出配置，也可把调整保存为当前浏览器的默认值。网址参数可切换内置暗色和亮色预设。
- **动态壁纸支持**：提供 Wallpaper Engine 与 Lively Wallpaper 用法。壁纸版可离线运行，被全屏程序覆盖时暂停画面与音乐。
- **移动端适配**：入口页在触屏设备上打开移动版，支持横竖屏切换，并降低粒子负载。

## 怎么安装和使用 haloflux？

所提供的 README 没有 DSH 安装命令，也未确认 npm 包名。需要会话驱动背景时，请进入其列出的社区插件仓库，按对应说明安装和配置；以下步骤用于体验上游画面。

1. 下载仓库文件，用 Edge、Chrome 或 Safari 打开 `index.html`。桌面可直接打开 `lab.html`，移动版为 `mobile.html`。
2. 双击画面或按 `F` 切换全屏，点击 `CONSOLE` 或按 `C` 打开参数面板。
3. 调整后可导出 JSON；保存为默认会写入当前浏览器。网址后添加 `?preset=a` 或 `?preset=b` 可选择内置预设。
4. 点击、轻触或按键启动背景音乐，用 `BGM` 按钮或 `M` 切换播放，再用滑块调节音量。

安装 Wallpaper Engine 壁纸时，从仓库发布页下载并解压 `HALOFLUX-wallpaper-engine.zip`。在 Steam 中浏览壁纸程序本地文件，将整个 `HALOFLUX` 文件夹放入 `projects\myprojects`，确认最终路径为 `projects\myprojects\HALOFLUX\project.json`，不要多套一层目录。

从托盘完整退出程序后重新启动，在已安装列表中选择壁纸。需要编辑时，通过打开壁纸、从文件打开，选择该 `project.json`。使用 Lively Wallpaper 时，选择添加壁纸并输入 `https://ryder191.github.io/haloflux/wallpaper/`。

## haloflux 报错怎么排查？

音乐显示 `CLICK / TAP TO PLAY` 时，先与页面交互，再检查音乐开关和音量。音量设置按浏览器分别保存，换浏览器后应重新确认。

壁纸未出现在列表中时，先检查目录层级及上述文件路径，再完整退出并重启壁纸程序。被全屏应用遮挡后暂停属于预期行为。

若社区背景没有在 DSH 中显示，可按通用步骤确认当前 profile、检查插件是否启用、重启宿主，并查看插件版本和日志。上游 README 未提供该集成的专用错误码或配置键，具体设置应以对应社区仓库说明为准。
