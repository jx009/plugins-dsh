## OpenViking 是做什么的？

OpenViking 是面向 AI 智能体的开源上下文数据库，通过 `viking://` URI 将知识、记忆和技能组织到虚拟文件系统中。开发者可以检查和编辑已存储的上下文，智能体则可以通过文件式操作访问这些内容。

资源用于保存文档和代码，记忆用于保留用户偏好与经验，技能用于描述任务执行方法。

## 核心功能

- 支持 `ls`、`tree`、`read`、`write`、`grep` 等上下文操作。
- 可将语义检索限定在项目目录或记忆子树内；`find` 直接执行查询，`search` 根据会话上下文规划检索。
- 分层加载上下文：L0 摘要用于初步判断相关性，L1 概览提供主要信息，L2 提供完整内容。经过语义处理的目录带有自动生成的摘要和概览。
- 提交会话后归档对话，并提取可检查、编辑和合并的 Markdown 记忆。
- 启用 VikingBot 后，可使用 `ov compile` 将源材料整理为 Wiki、知识图谱或报告。

## 怎么使用 OpenViking

README 提供了无需安装的 OpenViking Studio 浏览器演示，也列出了 Web Studio 自托管说明的入口。

使用已存储的上下文时，先定位到相关的 `viking://` 目录，查看摘要或概览，再按需读取完整内容。检索时可以限定项目或记忆分支；需要保存对话并提取记忆时，提交对应会话。
