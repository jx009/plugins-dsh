## pojia-next 是做什么的？

pojia-next 是一个替换客户端内置提示词的 DSH 插件，以独立 Windows 工具形式分发。它面向需要自定义 AI 身份设定的用户，让 DSH、WorkBuddy、ZCode 和 Codex 共用一份 `persona.md`，并通过图形界面完成应用、检查和还原。

在 DeepSeek Harness 插件目录中，它属于修改本地客户端文件的辅助工具，没有已确认的 npm 包名。各客户端的接入方式不同：Codex 使用 `config.toml` 中的 `model_instructions_file`，ZCode 涉及指令、记忆和技能文件。README 同时提示，修改第三方客户端提示词存在使用条款与账号风险。

## pojia-next 核心功能

- **统一人格文件**：四个目标客户端使用共同的人格内容。窗口底部可直接编辑 `persona.md`，保存后重新应用，便于保持身份设定一致。
- **只读演练**：点击「演练」可查看将要修改哪些文件，不执行写入。客户端状态灯也是只读检测结果，可先检查再决定是否操作。
- **备份与还原**：修改前自动备份，「还原」按记录的文件清单恢复原版。人格、日志和历史备份集中保存，方便回查。
- **固定口令自检**：在新会话发送指定口令，对照预期回复检查载入情况，不依靠模型对自身身份的泛泛描述。
- **自动重启与日志**：8.26 起，应用过程会结束占用补丁文件的客户端进程，完成后重新拉起。「日志」页展示步骤，便于定位中断位置。

## 怎么安装和使用 pojia-next？

README 没有提供 DSH 安装命令，因此这里不生成命令行安装步骤。8.42 更新说明将 DSH 调整为进群下载一体包，使用前应查看官网当前入口。

1. 从官网 `https://pojiaduan.cn/` 或仓库 Releases 下载压缩包并解压，运行其中的 exe，无需另装 Python。
2. 按界面完成启动协议确认和激活。新账号注册涉及 QQ 群验证，客户端只填写激活码；在线校验通过后会自动获取核心。
3. 查看客户端卡片、版本和状态灯，先点「演练」确认文件改动范围。
4. 在底部提示词编辑框修改人格并保存，勾选目标客户端，点击「破甲」。等待写入、自检及客户端重新启动完成。
5. 在目标客户端新开会话，单独发送 `破甲自检`。预期仅回复 `破甲自检成功`，不应附带其他说明。

单文件版本将人格、日志和历史备份存放在 `%LOCALAPPDATA%\破甲一键通\`。关闭窗口会最小化到系统托盘，需要彻底结束工具时，从托盘菜单选择「退出」。

## pojia-next 报错怎么排查？

- **窗口闪退或打不开**：README 将缺少 WebView2 运行时列为常见原因，尤其是精简系统，应先检查该运行时。
- **WorkBuddy 靶点未生效**：若安装在 `C:\Program Files`，可能是写入权限不足。8.43 提供「以管理员身份重试」来处理此问题。
- **自检回复不符**：先确认使用新会话。旧版工具需完全退出目标客户端，包括托盘进程，再重新打开；文档也建议从官方渠道重新下载原版。
- **客户端升级后失效**：升级可能覆盖补丁文件，先点「刷新」重扫，再重新应用。
- **找不到安装位置**：自动扫描失败后，可选 `B` 打开系统目录选择窗口，手动指定安装目录，工具会记住该位置。
