## Reactive Resume 是做什么的？

Reactive Resume 将简历编辑、求职信撰写、文档检查和求职申请管理集中在同一应用中。可以导入已有简历，也可以从空白文档开始，在编辑时查看页面排版结果。

仓库带有 `dsh-plugin`、`agent-skills` 和 `mcp-server` 标签。提供的 README 片段主要介绍应用功能，尚未说明这些集成的配置方式或具体能力。

## 核心功能

- 通过行内编辑和实时 PDF 预览调整内容，支持富文本、自定义区块和拖拽排序。
- 从 18 套模板中选择版式，调整字体、颜色、间距、纸张大小及 Semantic CSS 样式。
- 查看可读性问题、比对岗位关键词，并检查招聘软件读取到的文本。
- 在可搜索的文档库中管理简历与求职信，使用标签分类并恢复历史版本。
- 通过列表、看板、统计和日历视图跟踪申请，记录联系人、跟进事项与面试安排。
- 将简历导出为 PDF、Word、Markdown 或 JSON，也可生成公开分享链接。

## 怎么使用 Reactive Resume

在 `rxresu.me` 创建账户，导入简历或新建文档，然后选择模板。对照预览编辑内容、调整排版，完成检查后导出或分享。

保存岗位后，可以针对该岗位调整简历、起草求职信，并记录申请进展。可选 AI 功能需要连接自己的服务提供商。

项目支持自行部署，文档位于 `docs.rxresu.me`。提供的 README 片段未包含 DSH 安装命令。
