## Tulpa 是做什么的？

Tulpa 是一个通过 MCP 连接 QQ、微信和哔哩哔哩的 DSH 插件。它帮助开发者把聊天资料检索、群聊互动和视频信息读取交给现有 Agent，减少手动复制上下文的工作。在 DeepSeek Harness 插件使用场景中，它以独立 MCP 应用提供服务，三个平台分别授权。

QQ 可用于实时群聊，微信提供资料读取与草稿所需上下文，不支持发送消息；B站模块仍在测试中。资料虽保存在本机，必要消息片段仍会进入所选模型服务，启用识图也会发送所选图片。

## Tulpa 核心功能

- **OneBot 实时群聊**：接收实时事件，支持原生 @、引用，以及单独授权的看图和表情操作。持续聊天需要 HTTP 与正向 WebSocket。
- **聊天历史检索**：按关键词、人物、会话和日期找资料，再展开上下文。图片、语音和文件按需读取，轻量版可经 OneBot 下载 QQ 群原文件。
- **B站视频研究**：支持搜索、推荐流、分 P、带时间戳字幕、真实抽帧和评论分页。无字幕时可用已安装的本地 ASR 模型，缺失内容会明确返回。
- **人格卡与群聊学习**：内置小鲸鱼等角色，也支持 Markdown 自定义卡片。同账号同群可接续表达与黑话积累，学习参考与人物设定分开。
- **SnowLuma 自动配置**：准备固定版本 2.1.1，校验运行包、生成凭据并配置端口。已有独立安装可从高级选项导入。

## 怎么安装和使用 Tulpa？

README 未提供 DSH 安装命令，也未确认 npm 包名。先获取 Tulpa MCP 发行版，再按仓库 `doc/AGENT_SETUP.md` 的对应章节连接宿主。

1. Windows 10 / 11 x64 用户完整解压 ZIP 到可写目录，打开 `Tulpa/Tulpa.exe`。需要 .NET Framework 4.8，使用系统 WebView2 Evergreen Runtime，包内自带 Python。Linux x86_64 / ARM64 使用终端源码包与 `./tulpa` 入口。
2. 登录 QQ，在“OneBot 设置 → 连接 QQ”勾选协议与自动配置授权，点击“一键配置”；已有连接可从高级选项导入。
3. 点击“开始创建链接”，启用 QQ，选择群、持续聊天与发送权限，按需增加图片和表情权限。只参与实时群聊无需先导入整库历史。
4. 点击“一键开启 MCP”，按教程配置 DSH 并重连客户端。在外部 Agent 的专用对话中发起群聊任务。自定义人格放入安装目录的 `chatlocal/prompts/mcp_chat/`，重新列出即可发现。
5. 看B站时，先在账号设置扫码登录，再启用只读能力并刷新工具列表。查询 QQ 或微信历史时，先在“数据与同步 → 本机账号”核对账号，选择会话和日期，再授权记录及附件读取。

发送与群管理勾选后属于持续授权，工具调用会直接执行，不会逐条弹回审批。界面可停止群聊，但已发送消息不会因此撤回。

## Tulpa 报错怎么排查？

- Windows 无法启动：检查运行依赖与解压目录，不要从压缩包内直接运行，也不要把 GitHub 自动生成的源码压缩包当作安装包。
- 群聊中断：确认 HTTP 和正向 WebSocket 可用，并保持 QQ、OneBot、Tulpa 与外部 Agent 运行。宿主回合结束、预算耗尽或休眠都会影响持续推理。
- 人格修改未生效：停止当前聊天并重新开启，新会话才会采用更新后的设定。
- 查不到历史：核对账号、日期、授权范围及导入情况。客户端版本与本机缓存也会影响可读内容，无法保证恢复尚未取得的记录。
- 升级后连接异常：按保留数据教程备份更新，仍从原目录启动 EXE 并重连 MCP。改过的同名随包人格应提前另存。
