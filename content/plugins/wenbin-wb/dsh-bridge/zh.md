## dsh-bridge 是做什么的？

dsh-bridge 让运行在你电脑上的 DeepSeek Harness 可以从其他设备访问。你可以在局域网里用手机打开 DSH 界面，可以通过公网隧道从外面连进来，也可以直接在聊天软件里和机器人对话来操作它。

它适合这样的场景：在工位上启动了一个耗时较长的 Agent 任务，人离开之后还想看进度、批准某个操作，或者补发下一条指令。所有配置都集中在 DSH 设置里的“远程访问”面板，面板语言跟随 DSH 的中英文设置。

## 核心功能

- **局域网访问**：随 DSH 一起启动并显示二维码，手机连上同一个 Wi-Fi 扫码就能打开移动端界面。电脑有多块网卡时可以手动选择，选择结果重启后仍然保留。
- **公网隧道**：有三种模式，分别是免登录的 Cloudflare 临时隧道、绑定固定域名的 Cloudflare 隧道 Token，以及连到自己 VPS 的自建 WebSocket 隧道。公网入口每 60 秒探测一次。
- **移动端界面与 PWA**：针对手机做了布局，可以添加到主屏幕全屏运行；远程访问时用树形目录浏览器选择工作区。
- **访问控制**：二维码 Token 登录、访客密码、独立的管理员密码，还可以把管理权限限制在本机。
- **IM 机器人**：支持微信、QQ、飞书和 Telegram，可以在多个工作区之间调度，回复以流式输出，每轮结束后汇报改动了哪些文件。

## 怎么使用 dsh-bridge

1. 用本页显示的安装命令添加插件。DSH 桌面端使用独立的 `desktop` 档案，如果你用桌面端，需要在那里再装一次：

   ```bash
   dsh plugin --profile desktop add @wenbin_wb/dsh-bridge
   ```

2. 启动 DeepSeek Harness，打开左侧边栏的设置，点击“远程访问”。
3. 局域网使用：手机和电脑连同一个 Wi-Fi，扫描面板上的二维码。
4. 外网使用：在隧道区域点击启动，得到一个临时的 `https://*.trycloudflare.com` 地址；需要固定域名时，填入 Cloudflare 隧道 Token 和主机名。
5. 依赖隧道访问之前，先开启访问认证并设置密码。README 提醒，自建隧道在没有设置密码的情况下，任何知道地址的人都能连到你的 DSH。
6. 使用机器人：进入远程访问里的 IM 机器人，绑定对应平台（微信和 QQ 扫码绑定，Telegram 填 BotFather 给的 Token），然后发送第一条消息完成授权。
