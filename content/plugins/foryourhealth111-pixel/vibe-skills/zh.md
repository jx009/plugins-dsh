## Vibe-Skills 是做什么的？

Vibe-Skills 是一个支持本地技能路由与复杂工作流编排的 DSH 插件。它面向已经积累多种技能、却仍需手动判断调用对象和执行顺序的开发者。项目将自身定位为通用 Skill，通过协调已有能力，减少用户逐项指定技能和组织任务的负担。

在 DeepSeek Harness 插件使用场景中，它的主要价值是把包含多项交付要求的需求转成可执行计划：先澄清目标，再拆分可验证的子任务，为各部分选择相关能力，最后按依赖推进。技能选择因此与具体交付目标联系起来。

## Vibe-Skills 核心功能

- **本地技能路由**：从可用技能池中筛选相关能力。公开案例包含查看候选技能 `SKILL.md` 的过程，再将选中的技能安排到对应任务。
- **工作流编排**：依据子任务之间的依赖组织执行，让不同领域的技能参与同一个计划中的不同模块。
- **可验证任务拆解**：把复杂需求拆成有明确产出的工作单元，便于检查完成情况，并在交付前发现遗漏。
- **交付一致性检查**：核对所需文件、不同产出之间的一致性和核心复现结果。机器学习案例覆盖实验、图表、报告与演示文稿。
- **SkillsBench 评测**：v4.1.0 在包含 195 个专业技能的环境中，使用 DeepSeekV4Flash-VE 与 OpenHands 进行对比，报告平均验证奖励增加 21.12 个百分点、token 消耗降低 29.6%、工具调用减少 33.1%。

上述收益来自指定实验条件下与未使用该项目的基线比较。奖励分析涉及 82 个配对任务，资源分析涉及 81 个，不能直接视为任意宿主或任务的效果承诺。

## 怎么安装和使用 Vibe-Skills？

提供的 README 片段没有 DSH 安装命令，仓库信息也未确认 npm 包名，因此这里不生成安装命令。安装入口是仓库内的 `docs/install/README.en.md`，快速上手入口是 `docs/quick-start.en.md`；当前片段没有给出配置文件路径或技能目录设置项。

1. 先阅读安装指南，按实际宿主对应的说明完成部署，再通过快速上手文档确认启用方式和配置位置。
2. 提交任务时写清目标与交付物。可参考公开案例：使用公共数据完成分类实验，交付数据审计、统计复核、四张结果图、科学报告和七页演示文稿。
3. 执行前明确验收要求。案例是在需求和计划获批后，按照 `L` 工作流依序推进；具体调用方式需查阅完整文档。
4. 核对技能选择和任务划分。该案例从一百多个候选技能中选出七个，组织为五个工作组、十个工作单元，覆盖环境准备到最终报告的过程。
5. 查看最终文件及验收结果。案例报告十个工作单元全部完成，十七项检查全部通过，其中包括跨交付物一致性和核心复现检查。

以上步骤说明 README 展示的使用思路。实际安装参数、启用入口和本地技能目录应以完整安装指南为准。

## Vibe-Skills 报错怎么排查？

当前片段没有列出特定报错或修复方法。若能力未出现在 DSH 中，可先做通用检查：确认当前 profile 名称，核实已安装的插件或技能是否启用，并在修改配置后重启宿主。

随后记录所用版本，查看可用日志，区分加载失败与任务执行失败。对照安装指南和快速上手文档核实本地技能发现方式；评测环境只用于解释实验结果，不能替代当前宿主的配置说明。
