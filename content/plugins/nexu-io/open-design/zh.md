## OpenDesign 是做什么的？

OpenDesign 提供本地优先的协作设计工作区，让团队与编码智能体从需求简述出发制作设计，并根据反馈继续修改。工作区可管理原型、设计系统和媒体素材。

对 DSH 用户而言，README 明确说明了基于官方 `dsh` CLI 的原生运行时接入。OpenDesign 也通过技能、CLI 和 MCP 向智能体提供能力。

## 核心功能

- 运行 DSH，支持结构化流式输出、模型发现、取消和会话恢复。
- 在 Studio 中通过智能体对话制作交互式网页原型，并实时预览。
- 制作演示文稿，检查幻灯片和演讲者备注，再导出成果。
- 通过对话生成图像，查看结果并下载。
- 使用 HyperFrames 制作动态图形，并导出为 MP4。

团队可以检查和调整项目提供的技能、设计模板、设计系统及插件。仓库采用 Apache-2.0 许可证。

## 怎么使用 OpenDesign

从首页输入需求简述，或选择示例开始。使用编码智能体或 OpenDesign Cloud，依据设计系统制作原型，再分享给团队收集反馈，并在同一项目中继续修改。

在 Studio 中预览和调整产出；通过 Design Systems 页面查看品牌素材；在 Plugins 页面查找技能，并使用 `Try it` 启动。

DSH 通过官方 `dsh` CLI 集成运行。提供的 README 片段未包含 DSH 安装命令或完整的运行时配置步骤。
