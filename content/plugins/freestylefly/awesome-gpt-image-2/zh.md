## awesome-gpt-image-2 是做什么的？

awesome-gpt-image-2 汇集图像生成案例、提示词、模板和可复用 Agent 技能。DSH 用户可以将这些资源用于准备图像生成任务和组织 Agent 工作流。

仓库介绍了超过 530 个案例和 20 多套模板。配套网站提供可浏览的图库，另有独立的 GPT Image 2.5 专区，用于展示使用相同提示词生成的图像对比。

## 核心功能

- 按风格或场景筛选案例，查看大图并复制完整提示词。
- 提供模板和可复用技能，作为图像生成工作流的参考资源。
- 展示四个复现案例，保留原图库图片、完整提示词和生成记录。
- 支持拖动分隔线对比、并排查看图片及检查生成设置。
- 可以从网站案例返回 GitHub 中对应的源案例。

对比记录注明，原图的生成条件和工具的确切模型 ID 尚未核实；演示示例另有标注。

## 怎么使用 awesome-gpt-image-2

从仓库或 `gpt-image2.canghe.ai` 图库开始，按风格或场景找到合适案例，查看图片并复制完整提示词，用于自己的图像生成任务。需要复用工作流时，可进一步查看仓库中的模板和技能资源。

网站支持在 Google 登录后测试生成。若要查看已有对比，可进入独立的 2.5 专区；该专区未新增实时 2.5 图像生成功能。
