## What does awesome-gpt-image-2 do?

awesome-gpt-image-2 collects image generation examples, prompts, templates, and reusable agent skills. DSH users can draw on these resources when preparing image generation tasks and agent workflows.

The repository describes more than 530 cases and over 20 templates. A companion website makes the gallery browsable, and a separate GPT Image 2.5 section presents comparisons using shared prompts.

## Core features

- Browse image cases by style or scenario, inspect larger previews, and copy complete prompts.
- Use templates and reusable skills as resources for image generation workflows.
- Inspect four recreated cases alongside their original gallery images, prompts, and generation records.
- Compare images with a draggable divider or side-by-side view, and inspect generation settings.
- Return from a website gallery entry to its source case on GitHub.

The comparison records note that original generation conditions and exact tool model IDs remain unverified. Demonstration examples are identified separately.

## How to use awesome-gpt-image-2

Start with the repository or the gallery at `gpt-image2.canghe.ai`. Filter for a relevant style or scenario, open a case, and copy its full prompt for your image generation task. Review the repository's templates and skill resources for reusable workflow guidance.

The website offers generation testing after Google sign-in. Open the separate 2.5 section to inspect the documented comparisons; that section does not add live 2.5 generation.
