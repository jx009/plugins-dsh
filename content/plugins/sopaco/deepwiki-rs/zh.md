## deepwiki-rs 是做什么的？

deepwiki-rs（项目名 Litho）是面向 DSH 用户提供架构知识的 AI 代码文档生成工具。它分析源码，将仓库整理为结构化的技术说明，帮助开发者、架构师和技术负责人理解系统。当前 README 片段没有提供原生 DSH 插件的安装或调用方式，因此应将它的文档生成能力与具体接入方式分别确认。

输出围绕 C4 模型组织，覆盖系统上下文、容器、组件和代码层级。新成员可以借此了解系统边界，代码审查者也能结合组件关系理解修改背景。项目使用 Rust 开发，采用 MIT 许可证。

README 同时介绍了后续项目 Terrain，其中包含知识库同步，以及通过 ACP 向智能体提供知识的能力。检索 DeepSeek Harness 插件时，需要注意这部分说明属于 Terrain，不能直接视为当前仓库已经提供的接口。

## deepwiki-rs 核心功能

- **C4 架构文档**：从源码生成不同层级的架构说明和图表，并提取注释、代码结构及其关系，为阅读仓库提供系统化入口。
- **外部知识源集成**：支持引入 PDF、Markdown 和 SQL 等资料，让代码分析参考仓库之外的知识。具体挂载配置需要查阅完整文档。
- **数据库文档与 ERD**：针对 SQL 项目生成数据库模式说明和实体关系图，补充应用架构之外的数据结构信息。
- **多语言与模板**：README 列出 Rust、Python、Java、Go、C# 和 JavaScript 等语言，并提供可定制的输出模板机制；当前片段没有模板配置示例。
- **Git 历史与流水线**：支持通过提交历史分析架构演变，并将文档生成纳入 CI/CD。代码元素与文档之间还可以建立交叉引用。

## 怎么安装和使用 deepwiki-rs？

当前材料没有可核实的 DSH 安装命令，也未确认 npm 包名，因此此页不提供插件安装指令。README 展示了 crates.io 包入口，但截取部分未包含安装命令、运行参数或配置文件位置，暂时无法据此给出可直接执行的完整流程。

1. 先查阅仓库完整的英文或中文文档，确认目标版本的安装方式、运行环境和命令入口，再进行本地安装。
2. 选择需要生成文档的代码仓库，明确主要语言以及希望了解的系统、组件或数据库结构。
3. 判断是否需要加入 PDF、Markdown 或 SQL 资料。外部知识源挂载方式、模板选项及其配置位置，应以完整文档为准。
4. 按项目文档运行生成流程，检查 C4 各层级说明是否对应当前源码；SQL 项目还应查看数据库模式与 ERD 输出。
5. 需要持续更新文档时，再参考项目的 CI/CD 指南。当前片段只说明支持流水线集成，没有给出可以直接复制的工作流配置。

生成后可以了解配套阅读器 Litho Book。它提供 Markdown 渲染、Mermaid 图表、模糊搜索以及 AI 文档解读功能；这是生态中的独立工具，不应当作生成器自带的 DSH 界面。
