## awesome-dsh-plugin 是做什么的？

awesome-dsh-plugin 是一个提供分类导航、精选推荐和市场订阅的 DSH 插件目录。它面向想扩展宿主能力、却不确定该选哪个项目的用户，帮助读者从使用场景出发了解候选项目，再找到安装入口。仓库本身是发现资源，README 提供的接入方式是订阅索引源。

这个 DeepSeek Harness 插件导航项目每天抓取相关 GitHub 仓库并复核相关性，再按用途整理。你可以从桌面客户端、浏览器操作、界面工作台或视觉理解等需求出发，也可以查看热度榜和作者自荐，逐步缩小选型范围。

## awesome-dsh-plugin 核心功能

- **场景化精选推荐**：围绕用户想完成的任务组织条目，说明各项目的能力与适用方向，并配有界面截图，便于进入仓库前先理解用途。
- **分类全量目录**：`CATALOG.md` 是按类目分册的总入口，生态全景则用于快速定位方向，适合按领域浏览更广的项目集合。
- **热度榜与作者自荐**：首页提供 Top 50，`TOP200.md` 展示更完整的 Star 排行；`SHOWCASE.md` 汇集作者提交的项目。
- **官方发现页订阅**：添加索引后，可在宿主内按分类、编辑推荐、关键词、npm/Git、更新时间或 Star 筛选，再查看版本要求并安装。
- **机器可读数据**：`data/repositories.json` 提供含星数、许可证和活跃度等信息的每日快照；`data/market-v2.json` 面向下游市场，限制为最多 1000 条、1 MB。

## 怎么安装和使用 awesome-dsh-plugin？

README 没有提供该仓库的 DSH 安装命令，也未确认 npm 包名，因此使用订阅方式接入。第三方索引源功能要求宿主为 V0.2.1-rc.2 或更新版本。

1. 在左侧进入“插件”，打开“实验性插件”旁的“更多”菜单，启用“自定义插件市场”。随后应出现“已安装”和“发现”标签。
2. 进入“发现”，首次使用时点击“添加索引源”；已有市场时，从左上角市场下拉菜单进入“管理索引源…”。
3. 粘贴 `https://bruc3van.com/dsh-plugins/index.json`，点击添加。
4. 在市场菜单中选择“Bruce 的精选插件”，按当前需求浏览分类或使用筛选条件。
5. 查看目标插件声明的宿主版本要求，再执行安装；列表数据未更新时点击“刷新”。

需要更广的选型范围时，可以继续阅读全量目录和排行。订阅索引只收符合条件的 npm 目标与固定完整提交的 Git 组合包，按 Star 降序取前 1000 个，因此数量不会等同于全量目录。收录不表示已经完成安全审查，也不保证实机兼容。

## awesome-dsh-plugin 报错怎么排查？

看不到“发现”标签时，先核对宿主版本是否达到最低要求，再确认自定义插件市场开关已经开启。这两项是 README 明确列出的入口检查条件。

能看到入口却找不到精选市场时，检查是否手动添加了索引源。开启功能不会自动建立订阅；添加后还需要在市场菜单中选中对应来源。数据看起来陈旧时，使用页面的“刷新”操作。

仅为订阅发现页，无需额外安装 `safer-dsh-market`。独立市场界面、多选安装和安装后 AI 审查属于另一入口，不能把它与官方订阅设置混为一谈。若某个具体插件安装失败，应回到该项目的说明核对版本要求和排查指引。
