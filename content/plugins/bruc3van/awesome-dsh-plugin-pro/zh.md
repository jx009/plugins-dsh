## awesome-dsh-plugin-pro 是做什么的？

awesome-dsh-plugin-pro 是一个提供审核目录与订阅源的 DSH 插件资源项目，帮助开发者按实际需求找到扩展能力。它筛除蹭标签及非插件仓库，再把收录项目整理为场景推荐、分类目录和热度榜，减少从零筛选仓库的工作。

这份 DeepSeek Harness 插件目录可以直接阅读，也能接入宿主官方发现页，或通过独立市场浏览。仓库自身没有已确认的 npm 安装包；目录、订阅数据与使用这些数据的市场插件，需要分别理解。

## awesome-dsh-plugin-pro 核心功能

- **经审核分类目录**：`CATALOG.md` 是全量目录入口，按类目链接到各分册。覆盖界面体验、浏览器操作、开发工具、知识研究和 Agent 工作流等方向，适合按能力范围查找项目。
- **按场景精选推荐**：从桌面客户端、上下文查看、浏览器操作等具体需求出发介绍候选项目。推荐优先考虑社区验证较充分的项目，也包含部分具有独特用途的小型项目。
- **社区热度榜**：首页展示 Top 50，`TOP200.md` 提供完整 Top 200。精选推荐并非直接按星数排序，查找解决方案与浏览热门项目有不同入口。
- **官方发现页订阅**：通过索引链接把精选内容接入宿主，在界面中按分类和标签筛选。实际安装仍交由官方插件管理器执行。
- **机器可读数据**：`awesome-dsh-plugin-feed` 提供带 `install_status` 和安装映射的市场目录；`data/repositories.json` 提供每日仓库快照，包含星数、许可证与活跃度等信息。

## 怎么安装和使用 awesome-dsh-plugin-pro？

README 没有提供该目录自身的 DSH 安装命令。使用官方发现页订阅时，无需额外安装插件，但宿主版本必须达到 `V0.2.1-rc.2` 或更高。

1. 打开左侧导航栏的「插件」页面。
2. 在「实验性插件」旁打开「更多」，开启「自定义插件市场」。
3. 切到「发现」，点击「添加索引源」，也可从左上角下拉菜单进入「管理索引源…」。
4. 粘贴 `https://bruc3van.com/dsh-plugins/index.json` 并添加。
5. 在下拉菜单选择「Bruce 的精选插件」，按分类或标签查找所需项目，再执行安装。

如果需要独立市场界面，在官方插件安装界面输入 `dsh-market-pro`，安装并启用。随后可从左侧「插件市场Pro」、插件页顶部标签或会话右侧边栏进入。该市场提供发现与安装、已安装插件启用停用、检查更新、技能浏览和安装后 AI 安全审查；这些属于市场应用的功能。

只阅读仓库时，可用 `CATALOG.md` 浏览分类、用 `TOP200.md` 查看热度、用 `SHOWCASE.md` 查看作者自荐。程序读取市场数据可使用 `https://cdn.jsdelivr.net/npm/awesome-dsh-plugin-feed/data/market-catalog.json`；实现消费逻辑前，应阅读 README 引用的数据协议，确认字段与安装映射含义。

## awesome-dsh-plugin-pro 报错怎么排查？

所提供的 README 没有列出具体错误码或对应修复方案。发现页无法使用时，先核对宿主版本、自定义插件市场开关、索引地址，以及当前选中的订阅源是否正确。

如果独立市场入口没有出现，检查当前使用的 profile，确认对应插件已经安装并启用。仍无变化时可重启 DSH，再查看版本和日志；排查时区分索引加载问题与某个插件自身的安装问题。

目录收录不等于安全或兼容性保证。选定具体插件后，还需阅读它自己的安装说明与依赖要求，不能仅凭入选推荐或热度排名判断是否适合当前环境。
