## token-monitor 是做什么的？

 token-monitor 是一款以本地使用为主的桌面监控工具，用来查看 AI 编程工具的 Token 用量、费用、额度和会话活动。它面向同时使用多种工具、想在同一个界面核对消耗的用户。仓库介绍列出了 54 种以上的工具和服务，包括 Claude Code、Codex、Cursor 和 OpenCode。

如果你是从 DeepSeek Harness 插件市场找到这个项目，可以把它当作独立的桌面用量看板。支持清单中出现了 DeepSeek，但当前资料没有说明它能否直接读取 Harness 会话，也没有给出在 DSH 内启用的步骤。

## token-monitor 核心功能

- **用量与费用**：在主窗口查看实时消耗，也能回顾历史趋势。想知道某段时间为什么用量较高，可以按工具或模型拆开看，不必只盯着总量。
- **工具额度**：把额度信息与用量统计放在同一应用中查看。两项数据不是一回事，某个工具能显示多少内容，要以它自己的支持条目为准。
- **会话与项目明细**：按会话、项目或设备查看统计。比如发现某个项目的消耗较高，可以再从会话维度检查用量集中在哪些活动上。
- **多设备同步**：应用支持实时同步，也能按设备拆分统计。跨机器工作时，可以先看整体趋势，再区分不同设备的消耗。
- **桌面展示**：除了主窗口，还可通过菜单栏、系统托盘或屏幕边缘入口查看数据；在适用的 Mac 上还有刘海面板和原生小组件。菜单栏和托盘支持选择预设或组合展示项，例如额度进度、重置时间和费用。

## 怎么安装和使用 token-monitor？

当前 README 片段没有提供 DSH 安装命令。要使用已明确说明的功能，请安装仓库发布的桌面版，而不是在 DSH 的 `profile` 里配置它。

1. 打开 `Javis603/token-monitor` 仓库的发行页面，选择与你的系统相符的版本。仓库标注的支持范围是 Windows 10 及以上、macOS 13 及以上，以及 Linux x64。
2. 启动应用后，先从主窗口查看工具用量。建议先选一个你熟悉的工具核对数据，再按项目、模型或会话切换统计维度，弄清每个数字对应的范围。
3. 如果只想在工作时快速扫一眼额度或费用，可以在应用的菜单栏或托盘展示中选择预设，或按自己关心的数据组合展示项。需要对比趋势或查会话时，再回到主窗口。
4. 如果要把多台设备的数据放在一起看，请查阅完整项目文档中的同步说明。当前片段仅确认有同步功能，没有给出配对步骤或配置项。

## token-monitor 报错怎么排查？

- **桌面版打不开**：先核对操作系统版本、处理器架构和下载的发行包是否匹配，再重启应用。如果问题仍然存在，记下应用版本和出错时的操作，并检查是否有可用日志。
- **只有某个工具没有数据**：在完整 README 的工具支持说明中找到对应条目，分别确认它是否支持用量、额度和会话详情，并核对文档标注的数据来源。不要把某一列没有数据直接判断为整个工具接入失败。
- **在 DSH 里找不到入口**：先确认你安装的是桌面版还是有文档明确支持的 DSH 集成。桌面版应从系统应用入口启动；仅切换 `profile` 或重启 Harness，不会让独立应用出现在插件列表里。
