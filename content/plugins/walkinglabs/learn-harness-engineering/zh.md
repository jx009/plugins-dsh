## learn-harness-engineering 是做什么的？

learn-harness-engineering 面向开发者，讲解如何构建编程智能体周围的运行系统，包括执行环境、状态管理、验证与控制机制。仓库包含 14 讲课程与 8 个项目，采用 MIT 许可证。

对于 DSH 开发者，课程中的 DeepSeek Harness 设计拆解可用于学习插件架构、能力边界与事件管线。

## 核心功能

- 使用指令、工具、环境、状态和反馈五个子系统分析 Harness。
- 对照学习 DeepSeek、Pi、Claude Code 与 Codex 的设计方式。
- 围绕自动化、工作树、技能、连接器、子智能体与外部状态学习循环工程。
- 通过节点、边、共享状态和路由理解图编排，练习并行执行与恢复机制。
- 提供英语、简体中文等 15 种语言的课程材料。

## 怎么使用 learn-harness-engineering

从仓库 README 选择语言，按课程与配套项目展开学习。需要研究 DSH 架构时，可阅读 DeepSeek 设计拆解；英文材料路径为 `docs/en/harness-designs/deepseek/index.md`。

实践自动化时，可先完成项目 07，比较目标循环、定时循环和生成与检查循环，再通过项目 08 将工作流表示为图，加入并行分支、条件回滚与人工审批。

提供的 README 未列出 DSH 安装命令。
