## awesome-harness-engineering 是做什么的？

awesome-harness-engineering 是面向 DSH 插件开发与工作流设计的 harness engineering 资源清单。它帮助开发者查找智能体周边环境的设计资料，涉及上下文、工具、执行控制、验证和任务状态，适合研究长时间运行的编码或研究任务如何保持可靠。

仓库收集课程、文章、研究资料、工具和参考实现。对 DeepSeek Harness 插件开发者而言，它的作用是提供选型与设计参考；所给 README 没有将其描述为可直接安装的扩展。目录强调工程相关性，普通智能体工具只有涉及上下文管理、评估或运行时控制等主题时才纳入范围。

## awesome-harness-engineering 核心功能

- **上下文与工作记忆：** 按上下文设计、信息交付、记忆和工作状态组织资料。片段中包含 Anthropic 的上下文窗口预算指南，以及 Manus 的实践文章，可作为研究信息如何进入智能体的起点。
- **评估与可观测性：** 目录设有评估设计、验证、质量门禁、遥测、追踪和性能分类，方便围绕结果检查与执行过程查找资料。
- **运行时与执行边界：** 将工具执行边界、授权、策略和运行可靠性分开整理，并提供运行时控制层、沙箱与执行基础设施的分类入口。
- **编码智能体课程：** 学习区包含 Codex 和 Claude Code 项目课程，以及涉及仓库指令、权限、测试和审查的资料。浏览器智能体教程还展示上下文裁剪、轨迹验证与重试的设计过程。
- **参考实现与基准：** 按编码任务、多智能体编排、浏览器和 MCP 集成整理实现方向；基准目录覆盖编码、计算机操作、工具调用等场景，便于按任务比较资料。

## 怎么安装和使用 awesome-harness-engineering？

所给 README 没有 DSH 安装命令，也未确认 npm 包名，因此这里不提供安装指令。使用入口是 `walkinglabs/awesome-harness-engineering` 仓库的 README；资源清单本身没有文档支持的启用步骤。

1. 先明确问题。任务状态容易丢失时查看上下文与记忆；无法判断任务是否完成时查看验证与评估，避免一开始就浏览全部工具。
2. 阅读 Foundations，建立模型、框架、运行时和 harness 的区别。该部分收录架构约束、仓库指令、长期任务状态与智能体循环等主题。
3. 选择课程或实例。学习区提供项目式课程和浏览器智能体演进教程，可以按编码任务或工具执行需求选择切入点。
4. 查找对应实现类别。编码任务查看 Coding-Agent Harnesses；浏览器与工具连接查看 Browser, MCP & Tool Integration。
5. 到选定项目中阅读安装与配置说明。本清单未定义 DSH 配置文件、profile 名称或激活开关，不能据此推导具体配置位置。

被目录收录表示资源与工程主题相关，并不证明它能直接接入当前环境。实际使用时，应以具体工具的文档说明为准。

## awesome-harness-engineering 报错怎么排查？

所给片段没有插件运行错误码，也没有 DSH 专用修复步骤。如果在插件列表中找不到它，先确认目标是否就是这份资源目录；文档没有提供将目录注册为插件的方法。

如果问题发生在另行选择的 DSH 扩展中，可按通用步骤确认 profile 名、检查插件是否启用、重启 DSH，并查看版本与日志。这些属于一般检查，不是本仓库声明的功能或已知故障解法。课程和参考实现的配置问题则应返回对应项目文档，记录所用资源及版本后再定位。
