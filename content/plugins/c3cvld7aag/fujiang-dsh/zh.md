## fujiang-dsh 是做什么的？

fujiang-dsh 是一个在 Windows 上为会话加载内置提示词规则的本地 DSH 插件。安装时不需要把规则逐条复制到对话里；安装完成并重启后，可以在输入框上方看到加载状态。这个 DeepSeek Harness 插件的本地标识是 `fujiang-armor`，与仓库名不同，查看安装目录时要用这个标识查找。

## fujiang-dsh 核心功能

- **内置提示词规则**：提示词随插件一起部署，不必另建文本文件或手动粘贴。插件加载后，可在聊天中发送激活词来使用规则。
- **自动准备运行环境**：安装器优先复用可用的 Node.js 22 或更新版本及 npm。环境缺失、损坏或过旧时，会从官方来源下载 Node.js 长期支持版并校验 SHA256；缺少 pnpm 时则通过 npm 获取。
- **选择目标配置**：检测到多个本地配置时，安装器会询问要装到哪个配置。想在平时的会话里使用，就选平时启动时所用的配置。
- **显示加载状态**：对话输入框上方的「富江破甲已激活」用于确认插件是否加载。实际回复还会受所选模型、其他提示词和 DSH 版本影响。

## 怎么安装和使用 fujiang-dsh？

双击运行 `点我一键注入.bat`。README 给出的是 Windows 批处理安装方式，没有列出 DSH 命令行安装命令。

1. 先安装并启动一次 DSH，确认 `%USERPROFILE%\.dsh` 已生成。首次安装需要联网，以便安装器在缺少组件时下载运行环境。
2. 下载发布页的 ZIP 安装包，或从仓库下载源码 ZIP。完整解压后，打开包含安装脚本的项目文件夹，不要把脚本单独移到别处。
3. 完全退出 DSH，再运行安装脚本。如果出现配置列表，选中实际使用的目标配置，也就是对应的 profile，然后等待安装结束。
4. 重新启动 DSH 并打开对话。看到输入框上方的激活提示后，在聊天中发送「富江」即可使用内置规则。安装后的插件目录是 `%USERPROFILE%\.dsh\plugins\fujiang-armor`。
5. 保留解压后的完整项目文件夹。需要卸载时，先退出 DSH，再运行其中的 `点我一键卸载.bat`；如有配置选择，选回原先安装的目标，完成后重启。

## fujiang-dsh 报错怎么排查？

- 找不到配置时，先启动一次 DSH，检查 `%USERPROFILE%\.dsh` 是否已经生成，再退出并重新运行安装器。若提示脚本或规则文件缺失，重新完整解压 ZIP，确认 `prompts` 和 `scripts` 等子目录都在。
- 运行环境或依赖下载失败时，检查网络能否访问 `nodejs.org` 和 npm 软件包源。校验未通过的下载包不会被使用；检查网络后再试，并保留安装器输出的报错信息。
- 安装结束却看不到激活提示时，先完全退出再重新启动 DSH，然后核对当前使用的 profile 是否与安装时选中的一致。如果没有选对，退出后重新运行安装器并选择正确的配置。
- 如果 DSH 反复重启，且正在使用 `dsh-purge` 1.1.52，优先按该项目的官方说明升级到 1.1.53 或更新版本。这一旧版可能因补丁戳缺少 `sha` 而反复请求重启，不要随意填值。升级后仍有循环时，保留启动日志，并核对实际启用的版本和 profile。
