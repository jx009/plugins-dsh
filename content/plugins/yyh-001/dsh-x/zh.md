## DSH-X 是做什么的？

DSH-X 是一个用于多实例启动、版本管理和 DeepSeek Harness 插件管理的桌面启动器。需要同时保留日常环境和插件测试环境时，可以给它们建立不同的启动项，分别选择版本、配置和端口。这个社区项目负责启动和管理环境，打开的仍是官方原版 Web 页面，不是重新制作的界面。

## DSH-X 核心功能

- **多实例启动与隔离**：每个启动项都能指定用户目录、配置、版本和端口，已有启动项运行时也可以新增。只想分开 DSH 插件和配置时选插件隔离；连会话、记忆和技能也要分开时选会话隔离。
- **版本管理与锁定**：检测已安装的 DSH 版本，按需安装、卸载或清理，并查看磁盘占用。给启动项锁定版本后，日常环境和测试环境可分别使用选定的版本。
- **插件市场与整合包**：从在线市场安装插件，再按配置控制启用状态。实例可锁定 DSH 版本和插件组合，支持导入导出，并兼容 DSH-PackForge v5 的 `.dspack` 格式。
- **WSL 与 SSH 远端启动**：在「设置 → 远程管理」维护连接，再让启动项运行在 WSL 或 SSH 主机上。使用 SSH 时，服务在远端运行，页面通过 SSH 隧道在本机打开。
- **MCP 与技能市场**：从启动器内的在线市场查找 MCP 和技能。打开 Web 页面的方式可另行选择，包括内部标签页、独立窗口和系统浏览器。

## 怎么安装和使用 DSH-X？

1. 到 `yyh-001/DSH-X` 仓库的 Releases 页面下载对应平台的安装包。Windows 使用 x64 安装程序；macOS 按 Apple Silicon 或 Intel 芯片选对应的 `.dmg`，将应用拖入「应用程序」；x64 Linux 可选 AppImage 或 `.deb`。AppImage 需要先赋予执行权限。
2. 保持联网并首次打开启动器。安装包只带 Electron 外壳，应用会从 npm 下载当前通道的 `dsh-x-core`，界面会显示进度。核心和外壳后续分别更新，不需要把这个核心包当作 DSH 插件手动添加。
3. 新建启动项并选择隔离方式。如果想继续使用已有会话，只换一组插件，保留默认的插件隔离；如果要从独立目录开始，选择会话隔离。自定义方式支持手动指定用户目录、配置和端口。不要把 DSH 用户目录或版本目录放进启动器安装目录。
4. 确认版本后启动。如果要修改插件开关，先确认启动项使用的是哪份配置；如果要导入整合包或管理其依赖，则进入「实例」页。

## DSH-X 报错怎么排查？

- **启动后日志图标变红**：先看原始日志定位报错，再到耗时页按插件查看启动耗时，需要核对磁盘占用时查看空间页。确认插件在当前配置中已启用，并检查它是否兼容启动项选用的 DSH 版本。
- **Linux AppImage 缺少 FUSE**：用 `--appimage-extract-and-run` 参数运行。若是在 Windows 上遇到 SmartScreen 的未知发布者提示，README 说明安装包暂无 Authenticode 签名，可按文档核对下载文件的 SHA256。
- **改完配置后无法正常启动**：启动器会在启动前保存配置层快照。可在「实例」页右上角或配置操作菜单找到恢复入口，回退配置并重装依赖。
