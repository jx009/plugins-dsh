## ElecKoi 是做什么的？

ElecKoi（电子爱）是一个面向 AI 角色扮演和角色卡创作的 DSH 插件生态项目，以独立客户端的形式提供。它用 DeepSeek Harness 运行角色和创作助手，支持 Windows PC 和 Android。想体验故事，可以直接和角色对话；想自己写故事，则可以从人物构想出发，请创作助手整理设定、补充细节，再由你审核。

如果你是搜「DeepSeek Harness 插件」来到这里，安装前要区分两件事：DSH 是电子爱使用的执行框架，电子爱则是你实际下载并打开的应用。客户端在本地运行，项目方不提供模型服务，需要你自行选择并配置服务。

## ElecKoi 核心功能

- **设定库按需检索**：角色可以根据当前剧情主动查找相关资料，只读取此刻需要的设定。比如剧情切换到新地点时，可以围绕该地点查看背景，而不是把整套世界设定都塞进每次对话。
- **创作助手协助写卡**：除了起草人物，助手还能修改设定库、变量、正则和形象素材。建议在预览里逐项核对修改，尤其是那些可能与已有剧情冲突的细节，确认后再保存。
- **剧情变量由工具更新**：人物关系、物品、事件等状态由专用工具读取、校验和写入，不靠解析角色回复里的固定格式。角色在台词中说拿到了钥匙，不等于物品状态已经写入。
- **角色卡可以带交互界面**：创作者可以用 `HTML`、`CSS`、`JavaScript` 和素材来展示角色状态。需要进一步了解角色前端、原生脚本或可导入示例时，可以看仓库中的作者 SDK 文档。

## 怎么安装和使用 ElecKoi？

仓库没有提供 DSH 安装命令，也没有可确认的 npm 包名。日常使用请安装平台对应的客户端；构建章节中的 `pnpm build` 是编译源码用的，不是安装命令。

1. 从仓库 README 进入「使用教程」，打开下载安装部分。Windows 用户按教程选择 Windows x64 安装包；Android 用户按教程选择对应的客户端版本。
2. 打开客户端后，参照教程里的「模型配置」章节，在应用内配置自己选择的模型服务。先确认简单对话能返回回复，再测试复杂的角色设定。
3. 想聊天时，从角色卡列表选定角色并开始对话；想新建或改写人物时，按教程进入角色卡编辑流程。可以先给出角色身份、故事背景和希望保留的设定，再让助手处理其余细节。
4. 预览修改时，先核对人物和背景，再检查变量与素材。保存后，可以用一个简短场景验证角色能否引用相关设定，以及预期的状态是否随剧情改变。

## ElecKoi 报错怎么排查？

README 没有列出具体错误码。先记下问题出现在哪一步，再按安装、模型和角色卡三个方向缩小范围：

- **安装或启动失败**：核对下载包对应的平台和版本。退出客户端后重新打开，记录应用版本和可用日志；如果你另外运行了独立的 DSH 环境，才需要检查那里的 `profile` 和插件启用状态。
- **所有角色都无法回复**：回到模型配置，核对当前所选服务和设置，再用最短的对话测试。记录是从未收到回复，还是在更换服务或配置后才出现问题。
- **只有某张卡表现异常**：用另一张卡做对照，再检查问题是否集中在设定引用、变量更新或前端显示。若作品来自 SillyTavern，也要确认它是否依赖电子爱未承诺兼容的扩展环境。
