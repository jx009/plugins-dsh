## legal-skills 是做什么的？

legal-skills 是一个面向法律研究、材料整理与文书处理的 DSH 插件技能集合。仓库实际分发的是 Agent Skills，现有 README 未提供 DSH 原生安装命令或兼容性验证说明。它面向既要办理法律业务、又要整理资料和撰写文章的法律工作者，将资料获取、格式转换与专业应用组织为可单独选用的能力。

在 DeepSeek Harness 插件选型中，这个项目适合关注法律工作技能扩展的用户。可以按任务下载单项技能，也可以选择诉讼、合同、知识产权等专家套件；具体加载方式需以宿主支持的技能机制为准。

## legal-skills 核心功能

- **微信公众号抓取**：`wechat-article-fetch` 使用 Playwright 无头模式获取文章，支持动态加载内容，并保存为 Markdown，方便后续研究和写作。
- **法律材料 OCR**：`legal-ocr` 支持 PDF、图片、Office 文档和 URL 转 Markdown，还可对法律术语及文书结构进行保守优化。
- **语音转文字**：`local-asr` 输出带时间戳和说话人的 Markdown；`tingwu-asr` 接入阿里云通义听悟，提供云端转录、说话人分离与 AI 摘要。
- **法律业务套件**：覆盖诉讼分析及文书撰写、合同审查与小微企业顾问、知识产权实务等场景。每个套件的能力范围和依赖应查看各自说明。
- **完整目录分发**：单项技能和专家套件均有 ZIP 下载方式。套件发布包会展开源码中的符号链接，让成员技能以完整目录交付。

## 怎么安装和使用 legal-skills？

README 没有给出 DSH 安装命令，也没有已确认的 npm 包名，因此不能生成插件安装命令。可先确认宿主如何加载 Skills，再采用仓库提供的下载方式。

1. 打开 `https://github.com/cat-xierluo/legal-skills/releases/latest`，选择所需技能的已发布 ZIP。单项下载是 README 推荐的方式，不需要 Git。
2. 解压并保留完整技能文件夹，将其复制到宿主规定的技能根目录。文档中的 `~/.claude/skills/` 是另一平台的示例，不能直接视为 DSH 路径。
3. 如需整套能力，下载 `suite-<id>-<version>.zip`，先读包内 README，再复制其中 `skills/*` 的成员目录。安装前检查依赖，并核对与已有技能重叠的版本。
4. 阅读所选技能的说明，按其要求完成配置和调用。现有摘录没有统一配置文件、凭据设置或通用调用命令，应以具体技能文档为准。
5. 按材料类型开始使用：文章选择抓取技能，扫描件选择 OCR，录音选择语音识别。专家套件只打包能力，不会自动编排成员执行顺序。

用于商业业务前，应逐项查看许可证。项目同时包含 MIT 与 CC-BY-NC 技能，后者的商业用途需要另行获得作者授权。

## legal-skills 报错怎么排查？

先核对下载包版本。README 明确区分源码版本和已发布 ZIP 版本，源码更新并不代表下载包已同步；应结合下载列和待发布备注判断实际获得的功能。

安装多个套件后出现变化时，检查重叠成员是否被旧包覆盖。仓库建议先比对版本，再处理同名目录；同时确认复制的是完整技能目录，而不是只取其中部分文件。

如果宿主未加载技能，可按通用步骤确认当前 profile、相关加载能力是否启用，重启 DSH，再查看版本和日志。现有 README 没有 DSH 专用错误码或修复命令；涉及依赖与配置的问题，应继续查阅对应技能或套件说明。
