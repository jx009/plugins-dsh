## dshcode 是做什么的？

DSHCode 是一个集成 DeepSeek Harness 插件运行时与 Web UI 的社区桌面客户端，适用于 macOS 和 Windows。想在本机使用 Agent 的开发者可以直接打开应用，在图形工作区里对话、查看计划或管理扩展。安装版自带运行环境，从启动本地服务到退出时释放端口，都由客户端处理。

工作区显示在 Electron 窗口里。每次启动时，应用只在本机回环地址 `127.0.0.1` 上监听，由操作系统分配可用端口，再由窗口打开本次分配的地址。日常使用时直接进入桌面应用即可。客户端以单实例运行，同时提供托盘图标和系统通知。

## dshcode 核心功能

- **插件管理**支持从 npm 或 Git 仓库添加 DSH 插件。管理器里可以检查更新，也可以按插件分别启用或停用，方便定位某项扩展带来的加载问题。
- **模型控制**按供应商保存配置。你可以调整推理强度和单次最大输出 token 数，也可以分别设置图像输入、图像生成和图像识别能力。
- **计划与目标**适合执行周期较长的任务。希望先看步骤再执行时，可以使用 Plan 模式审查计划；任务需要经过多轮对话时，可以用 Goal 模式保留目标，并在恢复会话后接着工作。
- **技能与交互卡片**分别用于扩展工作流和呈现结果。技能目录提供研究、文档写作等专项流程，GenUI 卡片则能直接在对话中呈现图表、表单或进度视图。

## 怎么安装和使用 dshcode？

1. 打开仓库发布页 `github.com/whitelonng/dshcode/releases`。使用苹果芯片的 Mac 选择 `macos-arm64.dmg` 结尾的文件，Intel Mac 选择 `macos-x64.dmg` 结尾的文件。Windows x64 对应的是 `win-x64.exe` 安装包。
2. 下载同一版本的 `SHA256SUMS.txt`，按文件名找到对应条目，核对安装包的 SHA-256 校验和。完成安装后，在 Mac 的“应用程序”文件夹或 Windows 的“开始”菜单中启动客户端。
3. 进入应用设置，填写访问 DeepSeek 官方 API 所需的 API Key，然后回到工作区开始对话。如果希望在 Agent 动手前核对操作步骤，选择 Plan 模式，读完计划再批准执行。
4. 需要增加工具时，打开插件管理器，选择对应的 npm 或 Git 来源安装，并确认扩展已经启用。要继续以前归档的任务，则进入归档管理，搜索会话并选择恢复。

## dshcode 报错怎么排查？

- **首次打开出现系统警告。** 预览版安装包尚未签名，macOS 版本也尚未公证。确认下载来源并核对校验和后，Mac 用户可以在访达中右键点击应用，选择“打开”并确认。Windows 用户可以在 SmartScreen 中选择“更多信息”，再点击“仍要运行”。
- **插件加载失败或影响启动。** 先看失败通知中的插件名和诊断信息，停用对应扩展。如果应用无法正常启动，可以改用安全模式。需要让 Agent 尝试修复时，选择通知中的修复操作，失败时的上下文会一并传给 Agent。
- **安装后模型调用失败。** 先在设置中核对 API Key。若要确认某次运行向模型提供了哪些内容，可以查看对应的会话日志，按当次请求的上下文排查。
