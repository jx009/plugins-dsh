## welink 是做什么的？

welink 是一个面向微信聊天记录分析的 DSH 插件项目，帮助用户检索历史消息、理解沟通变化，并根据聊天样本模拟联系人的表达方式。仓库标签包含 DeepSeek Harness 插件相关标记，但当前 README 片段主要介绍独立分析平台，没有给出已验证的插件包或接入配置。

平台采用本地优先设计，聊天数据库由用户自行管理。云端问答会发送问题及相关片段，远程训练会发送选定样本，因此应按实际服务理解数据流向。AI 分身生成的是模拟回复，不代表真人想法；分析结论也需要结合原始消息核对。

## welink 核心功能

- **跨联系人问答**：从问题中提取关键词与时间范围，调用搜索、日历 API 收集聊天记录，再生成回答。页面展示提供给模型的片段，并支持查看当天上下文。
- **AI 分身**：从私聊和选定共同群聊提取联系人的文本，支持选择 100、300、1000、2000 或全部消息。群聊按发送者过滤，可补充职业、籍贯和关系等背景。
- **群聊模拟**：选择参与成员、话题场景和聊天氛围，按成员的表达特征与发言比例生成对话。支持多轮互动，用户也可以加入。
- **提示词模板**：各 AI 功能可查看当前系统提示词，在设置页编辑对应模板。支持联系人、日期、轮数等变量，修改后即时生效。
- **SFT 工作台**：选择私聊或导入 JSONL，审核后冻结训练、验证和测试数据。支持 MLX 与 LLaMA-Factory Worker，可训练 LoRA Adapter、对比模型、人工盲评并导出或接入结果。

## 怎么安装和使用 welink？

当前材料未提供 DSH 安装命令，也未确认 npm 包名，不能生成可靠的安装指令。仓库描述列出 Docker、Windows 和 macOS，README 标注 Windows 10+、macOS 12+；具体部署步骤应以完整文档为准。

1. 按对应环境的部署文档准备平台和聊天数据库。当前片段没有数据库导入命令、模型凭证字段或 DSH 接入参数，无法据此给出完整配置文件。
2. 先用一个主题或日期范围进行跨联系人问答，检查回答下方的消息片段，再判断生成结论是否符合记录。
3. 使用 AI 分身时，选择联系人和消息数量，按需勾选共同群聊、填写背景信息。后续多轮对话可复用已缓存的学习结果。
4. 进入设置页的「Prompt 模板」调整功能指令，通过「查看 Prompt」核对当前内容。模板可使用 `{{name}}`、`{{today}}` 等变量。
5. 在 AI 首页切换「我的口吻回复」，粘贴对方消息并选择语气、模型，生成可编辑草稿。该功能只发送手动输入内容，不自动读取历史聊天，也不保存或发送草稿。
6. 需要个人模型时，在 SFT 工作台完成数据准备、环境连接、预检、训练和评测，再部署并接入模型配置。普通模型不会因使用回复助手就自动学会你的口吻。

## welink 报错怎么排查？

README 片段没有错误码或完整故障清单。若已自行配置接入但在 DSH 中找不到能力，先核对安装方式和目标 profile，再确认插件已启用、重启程序，并查看版本与日志。

搜索未命中时，可调整关键词或时间范围，检查候选消息和原文上下文。检索只提供有限候选，空结果不等于历史记录中不存在相关内容，引用编号也不能保证模型推断正确。

提示词修改后表现异常，可清空对应模板恢复默认。在线 Demo 不允许上传训练数据或连接训练环境，这是已说明的限制；SFT 主要学习表达习惯，涉及具体历史事实时仍应结合聊天检索核实。
