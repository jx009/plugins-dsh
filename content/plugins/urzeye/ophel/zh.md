## ophel 是做什么的？

ophel 是一个帮助用户导航长对话、整理会话和复用提示词的 DSH 插件。比如你在一次需求讨论里先梳理目标，再比较方案，最后确定交付范围；想回看当时为什么放弃某个方案，可以先从对话大纲跳回那一轮，而不是从头翻聊天记录。确认结论后，再把相关片段导出，留作下一次讨论的材料。

项目 README 展示的主要使用场景是 AI 聊天网页。内置站点适配覆盖 ChatGPT、Gemini、Claude、Grok、DeepSeek 等平台。常用多个平台时，可以沿用相近的大纲导航和会话整理方式，不用在每次换站点后重新摸索怎么回看长对话。

## ophel 核心功能

- **对话大纲**：从聊天内容生成可跳转的目录，支持按层级折叠、搜索条目和添加书签。只想保留讨论脉络时，也可以复制大纲，而不必导出整篇对话。
- **会话文件夹与标签**：文件夹适合按项目归档，标签适合标记跨项目的主题。会话可从来源站点自动同步，整理时支持批量操作和拖动排序。
- **全局搜索**：统一检索会话、大纲、提示词和设置，支持模糊匹配。结果太多时，可以用 `folder:`、`tag:` 或 `date:` 按目录、标签或日期筛选。
- **提示词库**：把常用问题按类别保存，需要时一键插入。固定结构可以做成带变量的模板；需要连续发出多条提示词时，还可以用提示词链和队列按顺序发送。
- **对话导出**：支持 Markdown、JSON 和 TXT，也能用 ZIP 打包图片和附件。想留存单个结论或一段推导时，选用分段导出即可。

## 怎么安装和使用 ophel？

当前 README 片段没有给出 DSH 安装命令，也没有说明它在 DSH 中的配置入口。下面按 README 能确认的浏览器版入口说明，不把浏览器扩展安装当作 DSH 插件安装。

1. 在 Chrome、Edge 或 Firefox 的扩展商店中找到项目对应的浏览器扩展并安装，然后打开一个受支持的 AI 聊天网页。
2. 先选一条已有多轮问答的会话，在大纲中点选一项，确认能跳到相应位置。以后回查这段内容时，可先搜大纲；要反复回看的位置则可以加书签。
3. 在会话管理中建立文件夹、添加标签，再到提示词库保存一条常用提问。可以先把会随任务变化的部分设为变量，下一次提问时从库里插入并填写。
4. 如果目标网站不在内置范围内，到站点包（`Site Packs`）区域查找对应适配包。有匹配项时再安装，回来用一条现有会话检查大纲是否可用。

## ophel 报错怎么排查？

如果是在 DSH 中遇到插件没加载或没显示，先确认当前使用的 `profile` 是否和安装时一致，再检查插件是否已启用。重启 DSH 后重试；问题仍在时，记录 DSH 和插件版本，并查看启动日志，确认异常是在加载时出现，还是触发某项功能时才出现。

如果用的是浏览器版，先在浏览器的扩展管理页确认扩展处于启用状态，再核对当前网站是否有内置或已安装的适配。可以在一个已知受支持的网站打开多轮对话作对照，区分是扩展整体没有生效，还是只有某个站点没有显示大纲。
