## ccteam 是做什么的？

ccteam 是一个面向 DSH 插件生态的编程智能体协作工具。它把 DeepSeek Harness、Claude Code 和 Codex 等编程工具的会话放进同一个控制台，让已登记的会话可以发起委派、跟踪进度并收回结果。如果你是从 DeepSeek Harness 插件列表找到这个项目，先区分两个入口：编程会话在控制台里统一管理，DSH 则从控制台内的专用页面打开，并不是在 DSH 里用包管理命令添加整个工具。

## ccteam 核心功能

- **跨厂商任务委派**：可以让一个会话先拆分需求，再安排其他会话分别实现、测试或审查。发起方能查看子会话是工作中还是空闲，不必凭消息间隔猜测进度。
- **内嵌 DSH 网页**：打开控制台的 DSH 页面即可使用 DeepSeek Harness Web。守护进程负责启动或连接对应的本地网页实例，各登录用户使用独立的 DSH 主目录。
- **聊天内接收结果与审批**：Telegram、飞书和 Slack 可以接收完成通知与交付文件，也能在需要人工确认时选择批准或拒绝。Slack 用独立讨论串区分并行会话，避免把回复发给同一频道里的其他任务。
- **查看团队分工与费用**：团队页展示会话之间的委派关系、使用的模型、推理强度和费用。可以从关系图分别打开父会话和子会话，核对任务是怎么交接的。
- **远程节点执行**：项目可以绑定到指定主机，支持远程执行的会话在那里运行，记录仍集中在同一控制台。当前远程节点只执行 Claude 会话，其他厂商的会话在守护进程所在机器运行。

## 怎么安装和使用 ccteam？

现有 README 片段没有给出 DSH 安装命令，仓库信息也未确认 npm 包名。请先按仓库的安装说明完成独立安装，不要把仓库名当成 npm 包名。安装程序启动守护进程后，按下面的顺序使用：

1. 在终端运行 `ccteam status`，用浏览器打开输出中的控制台地址。要使用 DeepSeek Harness Web，进入侧栏的 DSH 页面。
2. 要新建编程会话，在网页启动区选择项目、主机、角色、厂商和模型，然后发送第一条消息。可以先在一个项目里试跑一项任务，再到团队页查看是否产生了子会话。
3. 要从聊天软件操作，打开控制台的 `Settings → Access`，为对应服务配置机器人。群聊和频道可设为仅在被提及时响应；先用一条状态查询确认消息能到达控制台。
4. 要添加远程主机，在同一设置页获取加入令牌并登记节点，再选择绑定到该主机的项目。切换项目时留意它绑定的机器，不要只根据项目名称判断任务会在哪里执行。

## ccteam 报错怎么排查？

打不开网页时，先重新运行 `ccteam status`，核对浏览器使用的是当前输出的地址。如果控制台能打开而 DSH 页面不能用，确认当前登录用户和所用的 DSH profile，再核对版本并查看相关日志。若已在本地调整 DSH 配置，可重启后再测试，留意问题是出在整个控制台还是只出在内嵌页面。

如果机器人不回消息，到访问设置检查发送者是否获准，以及群聊是否启用了仅提及时响应。Slack 下的状态命令用 `!status`，不能照搬其他聊天入口的 `/status`。如果任务没有在预期的机器执行，先核对项目绑定的主机，再确认会话厂商是否在当前远程执行的支持范围内。
