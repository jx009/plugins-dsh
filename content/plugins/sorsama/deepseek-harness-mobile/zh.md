## deepseek-harness-mobile 是做什么的？

deepseek-harness-mobile 是一个在安卓手机上控制 DeepSeek Harness 的非官方配套应用。它让开发者离开电脑后仍能跟进编码任务、回答智能体问题和审批命令。对在市场中寻找 DSH 插件的用户而言，这是手机端集成，而不是 README 已提供 npm 安装方式的扩展。

应用可通过局域网 Wi-Fi 或中继连接电脑，也可尝试内置 Harness，在手机上直接运行任务环境。它由社区开发，支持 Android 8.0 及以上系统；内置运行模式还要求 64 位手机。查找 DeepSeek Harness 插件时，应注意这里安装的是安卓客户端。

## deepseek-harness-mobile 核心功能

- **聊天与命令审批**：查看流式回复、推理内容、代码块和工具调用。支持照片及文件附件、用 `@` 引用文件、用 `/` 调用命令或技能，并可批准或拒绝命令、审阅计划。
- **目标进度与通知**：目标、待办、排队消息、后台任务和子智能体各有视图。回合结束、目标完成或受阻、等待用户回答时均可通知，连接可保持在后台。
- **会话与运行配置**：按项目分组或拖动排序会话，也能管理模型、智能体预设、插件、定时任务和归档会话。
- **文件预览与终端**：浏览工作区，预览 CSV、JSON、笔记本和 PDF 等文件，将副本保存到手机，或打开运行 Harness 的电脑上的终端。
- **手机端运行测试版**：下载包含 Node.js 的 Linux 环境，通过 `proot` 启动 Harness，支持仓库克隆、文件操作、智能体和 shell 工具。

## 怎么安装和使用 deepseek-harness-mobile？

提供的 README 没有 DSH 安装命令，也没有确认 npm 包名，因此不应将仓库名直接套入插件安装命令。请通过仓库 Releases 获取安卓应用。

1. 选择运行位置。连接已有电脑环境时，选择局域网或中继方式，在连接页粘贴 Harness 输出的链接，即可连接并登录。
2. 不用电脑时，在 `This phone` 页面点击 `Set up`。应用会下载、校验、解包环境，然后启动并登录内置 Harness。
3. 在 `Settings` → `Models` 添加模型服务商 API 密钥。首次下载约 155 MB，配置时需约 1.4 GB 可用空间，完成后约占 1.1 GB。
4. 选择命令策略。`Ask me first` 会完整显示每条命令并等待批准或拒绝，另一选项是 `Run it`。手机端环境不能为命令提供沙箱，也不能在本地运行模型。
5. 开始聊天后，在目标和子智能体视图中跟进任务。长按消息、工具调用或文件可查看复制、修改重发等上下文操作。

## deepseek-harness-mobile 报错怎么排查？

内置 Harness 从 0.22.0 引入，目前仍为测试版。README 仅说明在模拟器和一台三星手机上测试过，不能据此保证所有设备可用。

- 配置失败时，先核对系统版本、64 位要求和剩余存储；运行时还需约 300–400 MB 内存。
- 模型请求失败时，检查 `Settings` → `Models` 中的密钥及互联网连接。手机运行 Harness 不代表支持离线推理。
- 连接电脑失败时，重新确认地址和所选连接方式。可按通用步骤重启 Harness、查看应用及服务端版本，并检查可用日志。
- 内置环境的 Harness 页面提供启停、更新、存储和日志入口。若设备暂不兼容，README 说明电脑上的局域网或中继连接，以及 Termux 方式仍可使用。
