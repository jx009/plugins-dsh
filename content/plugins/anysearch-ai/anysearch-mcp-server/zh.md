## anysearch-mcp-server 是做什么的？

anysearch-mcp-server 是一个为智能体提供实时网页搜索和网页正文提取的 DSH 插件。它通过托管的远程 MCP 服务接入，不需要在本机启动搜索服务。还不知道资料在哪时，可以用自然语言搜索；已经拿到链接时，可以直接提取网页正文，不必先跑一遍搜索。

## anysearch-mcp-server 核心功能

- **通用网页搜索**：直接描述要找的问题或资料，适合从开放式问题开始，再根据结果缩小范围。
- **垂直领域检索**：支持金融、学术、法律、代码等领域的结构化查询。可以在请求里说明领域和要找的资料类型，例如请智能体查找某个主题的学术论文。
- **并行批量搜索**：一次调用可并行处理多个独立查询。例如，把待比较的几个产品分别列为查询，再请智能体汇总结果。
- **网页正文提取**：传入目标 URL，获取以 Markdown 表示的正文。需要核对搜索摘要里的细节时，可以选中原页面再提取。

## 怎么安装和使用 anysearch-mcp-server？

当前提供的 README 摘录没有 DSH 安装命令，也没有可确认的 npm 包名。接入时使用 DSH 的远程 MCP 配置，不要将其他客户端的安装命令照搬过来。

1. 在当前 DSH profile 对应的 MCP 配置中添加远程服务，可命名为 `anysearch`。将地址设为 `https://api.anysearch.com/mcp`，传输方式选 `Streamable HTTP`，不需要 SSE 或 stdio 代理。配置入口和字段以当前客户端版本为准。
2. 添加请求头 `X-Anysearch-Client: mcp/1.0.0`。如果只想匿名试用，保留这个请求头，不设置 `Authorization`。
3. 如需使用账户额度，可在 AnySearch 控制台创建 API 密钥。使用 `Authorization: Bearer <key>` 请求头；若客户端支持从环境变量注入请求头，可用 `ANYSEARCH_API_KEY` 提供密钥，否则只写入私有 MCP 配置。不要把密钥贴到聊天里，也不要提交到共享配置。托管端点不会读取本地 `.env`，也不接收本地 CLI 的 `--api_key` 参数。
4. 保存后重启 DSH，确认当前会话能看到该服务的工具。可以先发一条简单请求：“请用 AnySearch 查找某个项目的官方文档，再提取其中一个页面的正文。”这样能分别检查搜索和正文提取是否可用。

## anysearch-mcp-server 报错怎么排查？

- **工具没有出现**：检查配置是否写在当前使用的 profile 中、MCP 服务是否启用，然后重启 DSH。若仍未加载，确认客户端版本支持远程 HTTP，并在日志中查看连接或配置解析信息。
- **返回 `401` 或 `403`**：检查密钥是否填错、停用或过期，并确认请求头确实带上了 `Bearer` 值。无效密钥不会自动降级为匿名访问；若要匿名验证连接，移除 `Authorization`，保留客户端标识请求头。
- **返回 `402` 或 `429`**：前者表示额度用尽，先核对账户用量；后者表示触发限流，按 `Retry-After` 或响应正文给出的时间等待，避免连续重试。具体额度和并发限制以账户与服务响应为准。
