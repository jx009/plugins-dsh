## DSHA 是做什么的？

DSHA 是一个在安卓手机上提供完整 Linux 运行环境的 DSH 插件配套启动器。它把 Ubuntu、工具链和移动界面封装进 APK，让开发者免 ROOT、免 Termux 运行智能体。项目本身通过安卓应用安装，也提供 DeepSeek Harness 插件管理能力。

支持 Android 11 及以上、arm64-v8a 设备，不支持 Android 10 及以下。所给版本内置 Ubuntu 24.04、Node.js 24 和 pnpm 10.34.5，首次启动解压并校验环境。离线部署环境不等于模型服务可离线调用，提供商仍需在网页中配置。

## DSHA 核心功能

- **完整 Ubuntu 环境**：可使用 `apt`、Python、git 和交互式 PTY，支持原生模块编译。安装组件分别检查，失败时可以只修对应部分。
- **移动端 Web UI**：提供窄屏布局、手机快捷键及流式输出悬浮条。支持经鉴权的局域网访问，电脑或平板可使用手机上的服务。
- **安卓设备操作**：无障碍服务支持读屏、点按、输入和截屏，不依赖 ADB。无线直连无需 Shizuku；实验性虚拟屏需要额外授权设备通道。
- **应用内插件管理**：支持搜索、安装、更新和启停，可从多种 GitHub 链接、HTTPS 压缩包或本地文件导入。内置插件不可删除。
- **备份与迁移**：可导出对话、附件、设置和用户插件，也可按范围恢复。不同应用身份的数据与系统授权彼此独立。

## 怎么安装和使用 DSHA？

README 未提供安装此启动器的 DSH 命令，也未确认 npm 包名，应使用 APK 安装。

1. 确认系统版本和架构，从仓库 Releases 获取 Standard APK。所给发布资产包括 `dsha-0.2.2.apk` 及对应 SHA-256 校验文件。
2. 安装相应签名的应用，首次打开等待离线环境解压和校验；耗时取决于设备 I/O。
3. 环境就绪后进入主页，等待后台 Web 服务启动。打开 Web UI，在网页设置填写提供商、模型与 API Key。
4. 默认先使用 proot；需要尝试另一运行时时，在「配置」选择 proroot。按所需功能开启无障碍或设备通道，单独开启无障碍不会创建虚拟屏。
5. 在应用内管理插件。换机、换包名或卸载前，进入「数据与备份」导出，并把需要保留的文件存到应用外。

正式包名为 `dsh.android.client`，同包名、同签名可覆盖升级，操作前先正常停止服务。测试变体与历史包需要导出再导入，不能自动继承授权。本机备份副本不保证卸载后仍存在。

## DSHA 报错怎么排查？

- **环境部署失败**：进入「安装与修复」检查六项组件，按检查结果修补失败项，无需把健康组件全部重装。
- **Web 长时间未就绪**：先看主页进度和启动诊断。等待鉴权满 60 秒只是提示，不会因此强制结束慢启动。
- **proroot 启动异常**：检查「配置」中的运行时。自动回退仅针对鉴权前明确退出、且无插件故障的情况；确认 guest 退出后只重试一次 proot，慢启动不触发。
- **多版本同时运行冲突**：两个应用身份可能争用 Web 端口。端口支持自定义，自动回退时会给出说明。
- **PTY 终端异常**：个别机型可切换简易终端兜底，原会话保留在后台。
- **迁移后无法操作设备**：重新开启目标应用的设备授权和无障碍开关；这些权限不会随备份迁移。
