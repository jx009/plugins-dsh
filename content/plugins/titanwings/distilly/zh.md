## Distilly 是做什么的？

Distilly 根据消息、文档、访谈、公开资料以及用户描述，整理可复用的 Person Profile（人物档案）。档案汇集资料中体现的经验、判断方式、表达习惯与工作方法，供智能体使用。

项目原名为 Colleague Skill，目前覆盖工作关系、个人关系以及公众或虚构人物。当前版本将人物档案封装为 Agent Skill。

## 核心功能

- 同事类档案结合工作技能与人物特征，整理技术标准、工作流程和职场行为，并支持从飞书、钉钉和 Slack 收集资料。
- 关系类档案整理资料中的表达习惯、情绪触发因素、冲突模式和关系修复模式。
- 公众人物流程提供字幕处理、转录文本清理、研究资料合并和质量检查工具链。
- 三类人物分别采用对应的收集策略、分析维度和档案结构。
- 文档介绍 DeepSeek Harness、Claude Code、Hermes、OpenClaw、Codex、Pi、Grok Build 和 OpenCode 的本地技能发现方式。

## 怎么使用 Distilly

使用 `distilly` 创建技能，提供人物相关资料和描述，并选择适合的人物类别，以指导后续收集与分析。生成的人物档案以 Agent Skill 形式交由支持的宿主安装和调用。

采用本地技能安装方式时，README 要求将创建技能放在名为 `distilly` 的目录中。生成的档案以所提供资料为依据，描述可观察到的模式，不代表对真实人物的完整还原。
