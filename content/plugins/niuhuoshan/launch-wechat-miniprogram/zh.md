## launch-wechat-miniprogram 是做什么的？

launch-wechat-miniprogram 是一个面向新手、引导完成微信小程序设计、环境准备、开发和发布的 DSH 插件。它在 DeepSeek Harness 插件市场中归为智能体技能；仓库提供的是 Agent Skill，并未公布 DSH 专用安装命令。

只说“我想做个打牌记账器”，它不会替你决定人数、玩法或登录方式，而是先问清记账规则、是否需要多人查看，以及换手机后要不要保留记录。等你确认需求、首版范围和设计方向后，才进入源码开发。实名、扫码、提交审核和正式发布仍由你在官方平台完成。

## launch-wechat-miniprogram 核心功能

- **原生界面与高保真原型**：围绕同一业务页面比较微信原生、TDesign MiniProgram 和差异化设计三个方向。选定后先核对组件映射、底部安全区和导航；使用原生 `tabBar` 时，图标要用项目内的 PNG 文件。
- **账号、备案与后台判断**：在环境准备阶段梳理 AppID、微信开发者工具和备案事项。是否接入腾讯云取决于跨设备数据、多人共享等实际需求，开通前先确认费用和额外步骤。
- **已有项目盘点与产物校验**：修改前先查看页面、分包、导航、组件和云函数，局部更新沿用现有样式。只读脚本可检查配置、缺页和明显的打包遗漏，但不能替代实际运行。
- **分级测试与发布准备**：分别记录静态检查、模拟器、真机、体验版和正式环境的结果，不把一种环境的通过当成另一种环境的通过。提审前检查审核员能否进入关键页面，以及隐私声明是否与接口使用一致。

## 怎么安装和使用 launch-wechat-miniprogram？

README 没有给出 DSH 安装命令，也没有可确认的 npm 包名。请使用支持 Agent Skills 的环境，按下面的步骤安装和调用：

1. 将仓库地址 `https://github.com/niuhuoshan/launch-wechat-miniprogram` 发给 Agent，让它优先用当前环境的技能安装器，将整个仓库根目录安装到当前用户的 Skills 目录，而不是业务项目目录。没有专用安装器时，可让 Agent 从 GitHub 获取仓库后安装。
2. 核对实际入口是 `<Skills目录>/launch-wechat-miniprogram/SKILL.md`，不要多套一层同名目录。已有同名技能时，先查版本和来源，确认后再覆盖；`agents/openai.yaml` 是供 Codex 使用的可选界面元数据。
3. 安装后显式调用 `$launch-wechat-miniprogram`，说明要新建还是更新小程序，再给出目标用户、核心任务和已有素材。若已经有项目，先让技能盘点现状，再决定本次改动范围。
4. 确认需求并同意建档后，到业务项目的 `docs/miniapp/` 查看规划、进度、决策、测试报告和发布检查。这里可记录 AppID、腾讯云环境编号等非敏感标识，不要写入密码、验证码或 AppSecret。备案、类目和审核规则以操作时的官方页面为准。

## launch-wechat-miniprogram 报错怎么排查？

- **调用后没有加载**：先核对当前使用的 profile 或运行环境，以及技能是否已启用、安装入口是否正确。仍无法调用时，重启宿主，再检查宿主版本和日志。
- **不确定是技能还是项目有问题**：有 Python 时，在技能目录运行 `python scripts/validate_skill.py .` 检查技能本身。若要查业务项目的配置、页面或分包，改用 `python scripts/validate_miniprogram_artifacts.py <project-root>`，把占位符替换为小程序项目根目录。
- **静态检查通过但运行效果不对**：脚本通过只表示取得 L1 静态证据。原型和实际页面有出入时，先用微信开发者工具复核，再分别记录安卓和 iPhone 真机结果；体验版和正式环境另行验证。
