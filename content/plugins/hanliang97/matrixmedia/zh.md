## MatrixMedia 是做什么的？

MatrixMedia 是一个把多平台视频发布、账号查询和评论管理接入对话的 DSH 插件。它通过 MCP 调用矩媒工具：桌面端用于添加和登录创作账号，DSH 用于发起发布和查询任务。对于要维护多个自媒体账号的用户，可以先核对本机已登录的账号，再指定目标平台提交视频，不必为每次查询都切回桌面界面。

## MatrixMedia 核心功能

- **跨平台视频发布**：`publish_video` 可将视频提交到指定平台，支持定时发布，视频最长为 35 分钟。矩媒的自动化发布覆盖抖音、快手、百家号、哔哩哔哩、头条号、视频号、小红书和番茄视频。
- **账号与发布记录**：用 `list_accounts` 查看本机已登录账号，可按平台过滤。发布后用 `list_history` 按平台、状态或天数查记录，便于区分不同平台的任务结果。
- **账号与作品数据**：`get_account_stats` 读取已有的粉丝、播放和互动数据快照；需要采集最新数据时，可调用 `sync_account_stats` 更新快照。查询单条作品时，`get_work_stats` 使用视频的完整标题定位记录。
- **评论读取与回复**：`list_comments` 可读取抖音、快手和视频号已发布作品的评论。`reply_comment` 默认预演而不发送，确认内容和目标后才提交实际回复。

## 怎么安装和使用 MatrixMedia？

仓库说明提供了 DSH Web 的 Git 安装入口，未列出 DSH 命令行安装命令。

1. 在 DSH Web 进入「插件 → 添加插件 → Git 仓库」，按 `dsh-plugin/README.md` 的说明填写插件仓库地址。接入后，在当前配置档确认插件已启用。
2. 从矩媒的发行页获取适用于 Windows 或 macOS 的桌面应用，在账号管理中添加目标平台的创作账号并完成登录。通过 MCP 发布时，各平台都需要先在桌面端登录；不要等到提交任务后再在对话里扫码。
3. 回到 DSH，先让智能体调用 `list_accounts`，检查目标平台的账号是否出现在列表里。首次使用可以先选一个平台和一个账号，明确要发布的视频，再调用 `publish_video`。如果不是立即发布，还要在提交前核对定时时间。
4. 任务提交后，使用 `list_history` 查看本机的发布记录。向多个平台分发时分别核对各自的结果，不要用其中一个平台的回执判断其他任务也已完成。

## MatrixMedia 报错怎么排查？

- **安装后没有找到工具**：确认安装时使用的配置档与当前 DSH Web 配置档一致，检查插件是否已启用。重启 DSH 后仍未加载时，核对版本并查看日志，区分是插件未加载还是工具调用失败。
- **查不到账号或发布时提示未登录**：回到桌面端检查对应平台的登录状态，必要时重新登录，再运行账号查询。MCP 在无头环境中运行，不能弹出扫码窗口，重复提交发布任务也不能补上登录步骤。
- **没有确认发布结果**：先按平台和状态查询本机记录，再结合调用日志核对。缺少回执时先到创作后台人工确认，避免把结果不明当成失败而立即重传。
