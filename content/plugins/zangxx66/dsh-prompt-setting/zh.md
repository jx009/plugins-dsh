## dsh-prompt-setting 是做什么的？

dsh-prompt-setting 是一个在设置页查看和管理系统提示词的 DSH 插件。它面向需要调整系统级指令、核对每轮会话实际装配内容的用户，提供分段浏览、检索和修改对比，避免手工编辑全局安装目录中的文件。

这个 DeepSeek Harness 插件将配置保存在自己的数据目录中，宿主升级或重装不会覆盖这些配置。项目使用纯 JavaScript，没有运行时依赖，也不需要构建；README 标注的宿主兼容范围是 `>=0.2.1-0 <0.3.0-0`。

## dsh-prompt-setting 核心功能

- **分层指令编辑**：在 My Prompt 选择层后编辑并保存，文字会追加到全部内置段落之后，内置内容保持只读。恢复默认只删除当前层的自定义指令，保留其他覆盖项。
- **预设与标签**：保存可复用文本并应用到工作区，取消应用可恢复之前的内容。删除已应用的预设会先撤销应用；标签支持创建、重命名和删除，列表一次按一个标签筛选。
- **装配结果检查**：Prompt overview 提供段落状态、搜索、筛选、复制和全文查看，通过 `base ↔ effective` 差异核对修改结果。
- **历史与备份**：Version history 支持逐行版本对比，默认每页展示 50 条记录。Backup & restore 可以导出配置，并在导入写入前预览变更计划。
- **状态与更新管理**：Advanced 展示挂载状态、构建指纹、渲染自检和装配状态。更新检查可以关闭，安装新版本需要确认，重启由用户自行完成。

## 怎么安装和使用 dsh-prompt-setting？

提供的 README 片段没有首次安装命令，npm 包名也未确认，因此这里不生成命令。请先按仓库完整安装说明完成安装，不能仅凭仓库名推定包名。

1. 打开 Web GUI 设置，进入 Prompt settings，面板标识为 `prompt-setting`。
2. 在 My Prompt 标题下找到 View scope，选择本次保存的目标层，并核对面板显示的目标。
3. 输入系统级指令并保存。查看目标行下面的两行状态摘要，确认装配、投递结论及当前层的覆盖项计数。
4. 进入 Prompt overview，搜索相关段落，再查看全文与差异，核对实际装配结果。
5. 需要重复使用文本时，在 My presets 创建预设并应用到指定工作区；可添加标签整理预设库。
6. 继续调整前，可查看历史或导出备份。历史面板有独立的范围选择器，不随编辑面板联动；用户层日志是全局的，不按会话切分。

界面会即时跟随宿主语言设置，无须刷新或重启。插件覆盖八种界面语言，较旧宿主会回退到中文或英文。

## dsh-prompt-setting 报错怎么排查？

修改不生效时，先核对保存层和目标工作区，再查看编辑面板的状态摘要。点击 Details 可进入对应会话的 Advanced 详情，结合总览中的最终文本检查，不要只凭编辑框里的内容判断。

撤销修改时注意清理范围：Restore default 只移除当前层的自定义指令；clear all overrides 保留该指令；reset the whole layer 则连同它一起清除。后两项操作都有双重确认。

如果设置入口未出现，可确认当前 profile、插件是否启用，重启宿主并查看版本和日志。更新安装完成后，命令行用户需自行重新运行 `dsh web`，桌面用户需退出并重新打开应用。更新检查失败不会在页面顶部显示错误，因此没有横幅并不代表插件加载失败。
