## AIBanlv-Bot 是做什么的？

AIBanlv-Bot 是一个把桌面数字人接入任务执行流程的 DSH 插件项目。桌面应用内置 Harness，可以用文字或语音发起任务，由已配置的工具执行搜索、阅读或本机操作；如果你已经登录了 Harness 客户端，也可以通过仓库提供的 DeepSeek Harness 插件建立连接。桌面应用和连接插件不是同一个安装项：前者负责交互，后者用于关联已有客户端。

发出任务后，可以在数字人下方看进度和结果，按需收听语音汇报。窗口只展示可公开的执行信息，不显示模型的内部推理。电脑工具能否完成具体操作，取决于已配置的能力和授权范围。

## AIBanlv-Bot 核心功能

- **电脑操作**：由内置 Harness 选择已配置的工具，执行搜索、阅读和受授权的本机操作。在桌面窗口里就能查看任务进展。
- **Codex 与 WorkBuddy 协作**：可以将任务交给已安装并登录的外部助手，再查看返回的进展和结果。安装桌面伴侣不会替你安装或登录这两个服务。
- **3D 语音陪伴**：桌面形象在本机渲染，支持表情、口型和鼠标互动。可以打字或说话，也可以让数字人播报任务结果。
- **手机遥控**：绑定手机应用后，可以从手机下达任务，也可让桌面端将截图或指定文件发到绑定设备。发送前应先确认内容是否适合分享。
- **本地角色与记忆**：用 `SOUL.md`、`MEMORY.md` 和每日对话文档保存角色设定与记录。新增角色需要名称、提示词和获授权的声音文件，不导入形象资源也能沿用当前形象。

## 怎么安装和使用 AIBanlv-Bot？

仓库 README 没有提供 DSH 安装命令，也没有可确认的 npm 包名。先安装桌面端，有外部客户端接入需求时再配置连接插件。

1. 从项目官网的桌面伴侣下载页选择安装包。Windows 端面向 Windows 10/11 x64，Mac 端面向 Apple Silicon，桌面运行环境为 macOS 13+，具体要求以发行说明为准。从源码安装则先读 `docs/INSTALL_FOR_AGENTS.md`；Apple Silicon 的完整源码环境要求原生 macOS 15+，还需按 `docs/MAC_SOURCE_BUNDLE.md` 校验资源并完成本机自检。
2. 启动桌面应用后选择角色和使用模式。自备密钥模式下，用 Qwen Realtime Key 配置语音，用 DeepSeek Key 或已连接的 Harness 客户端处理文字和电脑任务。需要手机同步时，选择线上角色并通过手机应用扫码绑定。
3. 在桌面端开启所需的 AI 工具。要复用已登录的 Harness 客户端，按 `demos/web-desktop-pet/harness-client-plugin/README.md` 配置连接；要调用外部助手，先分别完成安装和登录。
4. 先用文字发一个目标明确的小任务，例如请它搜索某个主题并列出来源。在数字人下方确认结果后，再试语音输入或手机发任务，便于区分是任务配置还是输入渠道出了问题。

## AIBanlv-Bot 报错怎么排查？

- **桌面端装不上或启动失败**：先核对系统版本、CPU 架构和安装包是否匹配。源码安装时，对照安装文档检查初始化与资源校验是否完成，不要把安装包的系统要求直接套到完整源码环境上。
- **连接不上客户端**：确认插件装在当前 DSH 正在使用的配置档（`profile`）中并已启用，客户端也已登录。重启 DSH 后重试；如果问题仍在，记录桌面端和客户端版本，查看相关日志。
- **能对话但任务没有结果**：按所选模式检查密钥或客户端连接，再确认相关工具已经开启、获得所需授权。如果任务交给了外部助手，检查它是否已安装并登录。公开反馈前，请先移除日志里的密钥和私人对话。
