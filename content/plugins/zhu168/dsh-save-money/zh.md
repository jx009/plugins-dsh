## dsh-save-money 是做什么的？

dsh-save-money 是一个按指定时段暂停模型请求、到时自动恢复任务的 DSH 插件。它面向需要让长任务避开高峰计费或特定运行时间的用户，暂停时保留任务进度，没有任务运行时则不会暂停任何任务。

这个 DeepSeek Harness 插件按模型档位控制请求：被选中的档位在窗口内不发出新请求，新会话也可能暂时不回复；豁免档位仍可使用。配置前应先确定哪些服务需要等待，哪些需要持续可用。

## dsh-save-money 核心功能

- **多窗口与星期筛选**：可增删暂停窗口，支持 `23:00–08:00` 这样的跨午夜范围。全局星期与单个窗口的筛选必须同时匹配，默认全局只选工作日。
- **服务商与模型分级**：Official API 和 Other API 各有 flash、pro、vision 三个开关。默认暂停官方档位，豁免其他来源；没有这些名称标记的模型始终豁免。
- **时区与高峰预设**：支持 IANA 时区，自动检测浏览器设置，失败时回退到北京时间。预设去重添加 `08:58–12:02`、`13:58–18:02`，前后各留两分钟边界余量。
- **单次跳过窗口**：“End this save mode”可结束当前暂停或取消即将到来的暂停，不修改 Enable。跳过状态到恢复时间自动清除，下一窗口仍会生效。
- **余额与消费图**：可选每五分钟采样官方账户余额，悬停查看近期变化，点击查看八小时内的十分钟消费柱。没有本地活动却扣款的窗口用警示色标记，充值不画成消费柱。

## 怎么安装和使用 dsh-save-money？

提供的 README 在安装命令前截断，也没有可确认的 npm 包名，因此这里不生成命令。文档说明支持 npm 安装或仓库构建，采用导出 `apply` 的模块配合 `cordis.yml` 挂载；执行前请查阅完整安装章节。

1. 安装后，点击会话标题栏中 Session log 旁的 Save 彩色状态文字，打开设置面板。
2. 选择时区和星期，手动添加窗口或应用 DeepSeek 预设。预设会升级没有边界余量的旧窗口，但不会自动开启功能。
3. 勾选需要暂停的档位，未勾选即豁免。Other API 包括 SiliconFlow、中转服务和 opencode go/zen 等非官方来源。
4. 打开 Enable。距暂停不足五分钟时显示黄色提醒，进入暂停后显示红色状态，到结束时间自动恢复。
5. 如需查看余额，启用 Show balance。显示内容跟随最近一次实际请求的服务商，使用非官方来源时隐藏。

设置自动保存到工作区 `save-money.config.json`，刷新或重新启用插件后仍保留。余额历史另存于 `~/.dsh/dsh-save-money-balance.json`，跨项目共享并保留至重启后；更换 API Key 会清除旧密钥的历史。

## dsh-save-money 报错怎么排查？

AI 不回复时，先确认当前是否处于暂停窗口，以及所用档位是否被勾选。这属于预期行为；需要立即继续时，点击“End this save mode”。若要让被跳过的窗口重新参与调度，可关闭再打开 Enable。

没有按时暂停时，检查启用状态、时区、两层星期筛选和服务商档位。默认周末不匹配全局星期条件，名称没有 flash/pro/vision 标记的模型也不会被阻止。

余额消失时，检查 Show balance 和最近实际请求的来源。消费图出现警示色，表示余额下降时没有本地模型活动，可能来自其他设备，不能直接算作本地消费。若连设置入口都未出现，再确认 DSH profile、插件启用状态，重启并查看版本和日志。
