## dsh-degeneration-kit 是做什么的？

dsh-degeneration-kit 是一个折叠退化思考、自动管理上下文的 DSH 插件套件。它面向长任务开发者，处理回合看似成功、思考却持续复读，以及污染历史反复回传的问题。

这套 DeepSeek Harness 插件包含两个组件：`thinking-guard` 在后续步骤前折叠异常块，`dsh-auto-checkpoint` 用压缩或换会话清理累积污染。仓库建议一起安装，因为压缩之间仍有多步生成，单靠一种处理方式会留下空档。

README 区分两类复读：A 型反复重复同一句，B 型轮换多个短句。后者可能绕过单句占比判据。相关观察来自作者本机日志，不能直接当作所有模型的普遍结论。

## dsh-degeneration-kit 核心功能

- **退化思考折叠**：在下一次 pre-step 处理模型可见历史，减少异常内容再次回传；折叠本身不能打断正在进行的生成。
- **短句轮换检测**：`rotationGuard` 针对多个短句交替出现、每个单句占比都不高的复读形态补充检测。
- **自动检查点与压缩**：到水位后压缩或换会话，并落档任务状态。落档新鲜度同时检查时间和结论正文是否更新。
- **急停阀联动**：阀打断复读后，检查点组件默认额外压缩一次，不受水位和该会话面板处理模式限制。
- **实时水位配置**：浮动面板提供滑块、换会话勾选框和模式选择，滑块调整同时更新运行时与磁盘。

## 怎么安装和使用 dsh-degeneration-kit？

安装命令见仓库 `INSTALL.md`，当前片段未提供具体指令，也没有确认 npm 包名，因此这里不生成命令。

1. 按安装文档装齐两个组件并完成验证；详细行为分别查看 `thinking-guard/README.md` 和 `auto-checkpoint/README.md`。
2. 展开右下角浮动按钮。装有 `dsh-cost-whale` 时，也可从桌宠菜单进入，两个入口修改同一份配置。
3. 按窗口设水位：256K 建议任务边界 150k、落档或换会话 180k；至少 512K 建议 250k、350k；至少 1M 建议 350k、350k–500k。
4. 拖动滑块后直接生效，无需重启。这些数值是绝对 token 数，不按窗口比例放大；350k–500k 是经验范围，并非实测分界线。
5. 修改包内 `cordis.patch.yml` 的键后需要重启。关闭急停后的自动压缩，需全局修改默认值为 `true` 的 `AUTO_COMPACT_ON_VALVE_ABORT` 常量，再重启。

检查点用于接续任务，不等于长期记忆。会话中商定的方案、偏好和踩坑结论可能未进入摘要，需要另外的记忆方案保存。

## dsh-degeneration-kit 报错怎么排查？

- **面板不显示**：地址后加 `?acfloat=1` 强制打开；已有 `?token=...` 等查询参数时，在末尾加 `#acfloat`，不要再加问号。
- **压缩时报连接错误**：文档中的 `Connection error.` 等瞬时失败会在本轮递增间隔重试，不计 strike，也不进入冷却；真正的压缩失败另行处理。
- **落档看着新但内容旧**：检查本次压缩周期内是否更新，以及结论正文是否变化。仅追加文字或刷新修改时间不代表有效更新；催办仍未完成时也不会无限阻塞压缩。
- **安装或升级后未生效**：确认当前 profile、两个插件均已启用，再重启并检查版本与日志。完整运行验证版本是 DSH `0.2.1-rc.2`，内部接口变化可能影响兼容性。
