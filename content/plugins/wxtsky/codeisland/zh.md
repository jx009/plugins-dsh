## CodeIsland 是做什么的？

CodeIsland 是一个在 MacBook 刘海区显示编码智能体状态的 DSH 插件配套应用。它帮助同时运行多个会话的开发者查看任务进展、发现待审批操作，并直接回复问题，减少来回切换窗口。项目以 macOS 应用形式提供，现有资料没有确认 npm 包名或专用安装命令。

作为 DeepSeek Harness 插件生态中的状态面板工具，它还支持 Claude Code、Codex、OpenCode 等 30 多种编码工具。会话卡片集中展示当前活动和最新回复；对于通过 hooks 等待决策的工具，面板可以提交审批与问题答案，README 明确将 DSH 列入这一范围。

## CodeIsland 核心功能

- **实时会话状态**：查看各会话正在使用的工具与最新回复，完成后的内容支持 Markdown 列表、表格和代码展示。智能体自身的任务清单也能显示为进度条。
- **工具审批与回复**：支持批准、拒绝或始终允许工具调用，也能回答包含多个问题的提示。全局快捷键覆盖批准、拒绝、跳过和跳转操作。
- **项目上下文与跳转**：卡片展示 Git 分支和 worktree，可按项目或工具分组。点击能够定位终端标签页、IDE 窗口，以及受支持的 tmux、zellij 或 Herdr 窗格。
- **通知控制**：正在查看对应会话标签页时可抑制提醒，并提供安静时段、目录静音规则和可选的后续提醒，方便减少重复打扰。
- **远程与移动端配套**：SSH 远程会话可以和本机会话并排显示；iPhone 与 Apple Watch 提供额外查看入口，也可转发原始 webhook 事件用于自动化。

## 怎么安装和使用 CodeIsland？

当前 README 片段没有安装命令，仓库信息也没有确认 npm 包名，因此不能生成可直接执行的 DSH 包安装指令。请先查看仓库完整的安装章节和发布信息，按其说明安装 Mac 应用。已知系统要求为 macOS 14 或更高版本。

1. 按项目安装说明完成应用安装。README 表示它会自动安装受支持工具所需的 hooks，以连接编码工具与状态面板。
2. 在 `Settings → Hooks` 检查钩子相关配置。自定义 Claude 风格 CLI，以及部分工具的额外配置目录也在这里登记；现有片段没有给出独立的 DSH 配置路径。
3. 启动编码会话，在卡片中查看状态、当前工具和最新回复。会话较多时，可按项目或工具分组，并结合分支与工作树信息辨认任务。
4. 出现等待审批的操作或问题时，在刘海面板中响应。需要回到原工作环境处理细节时，使用跳转操作定位对应窗口或窗格。
5. 根据工作习惯设置安静时段、目录静音规则和可选提醒。SSH 与移动端配套功能的具体连接流程需要查阅完整文档。

## CodeIsland 报错怎么排查？

提供的片段没有专门的报错章节或错误码。会话不显示时，可先确认系统版本符合要求，检查 hooks 配置，并核对实际启动的 DSH profile 与相关集成启用状态。确认设置后重启 DSH；若问题仍存在，再查看应用版本和可用日志，定位会话是否被正确识别。

没有声音或通知时，先检查文档中已有的抑制规则：锁屏或休眠期间会静音，安静时段和目录规则也会影响提醒；正在查看对应标签页时，智能抑制可能避免再次提示。这些行为需要与会话未接入的情况分开判断。

单次工具调用失败不会播放错误提示音，只有整个回合异常终止才会触发该声音。若只是没有听到提醒，应结合卡片状态判断任务情况，而不要仅凭声音判断连接是否正常。
