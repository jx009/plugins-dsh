## workdsh 是做什么的？

workdsh 是一个管理项目、本地资料、专家、技能和连接器的 DSH 插件工作台。它面向需要持续推进任务、复用工作方法并保留交付物的用户，把相关管理页面集中到桌面应用中。其组织方式参考 WorkBuddy，功能通过 DeepSeek Harness 插件机制扩展。

用户可以从个人工作区开始，再按需安装企业连接。两种模式共用资料库、专家、技能和连接器；Agent 与工具在员工电脑上运行，企业服务器负责账号、授权、协作数据及模型转发。

## workdsh 核心功能

- **项目管理**：集中保存指令、计划、任务、资料与能力设置，为长期目标组织相关工作。
- **本地资料库**：管理文件，提供搜索和预览。任务可引用资料及其修订版本，明确使用的来源。
- **专家与技能**：专家保存角色及能力配置，技能承载可调用的指令和资源，便于重复使用已有方法。
- **交付物工作区**：对受支持的文档、表格、演示文稿、HTML 和 PDF 工作副本进行预览或编辑，让成果延续到对话之外。
- **企业协作与模型**：安装企业连接并登录后，可用 `@` 选择同事、分享文本和文件；公司模型可与个人供应商配置并存。

## 怎么安装和使用 workdsh？

现有 README 未给出工作台自身的 DSH 安装命令，也未确认 npm 包名。请从仓库的 Desktop 下载入口开始；所给资料链接指向 `desktop-v3.0.0-alpha.4`。桌面版包含 Node.js、pnpm、Python 和内置插件，社区扩展按需安装。

1. 打开桌面版，在项目中整理目标对应的指令、计划、任务和能力设置，集中管理持续进行的工作。
2. 在资料库管理来源文件，从任务引用相关资料及版本。按需使用专家配置和技能复用角色设置、指令与资源。
3. 在交付物工作区处理受支持的工作副本，根据文件可用的能力进行预览或编辑。
4. 需要企业功能时，从仓库发布链接下载 `workdsh-enterprise-connection-0.1.0-alpha.2.tgz`。在“插件 → 添加插件”填写文件完整路径，安装并激活；该扩展未上架插件市场。
5. 到“设置 → 企业账号”连接公司账号，通过模型设置添加公司模型，再在会话模型选择器中选择。登录后可使用同事提及及协作分享。

开发业务插件时，应在 Host 入口使用 `workdshEnterprise`，而非浏览器页面。该服务需要企业连接与公司登录，由 Desktop Main 认证请求，后台检查成员和业务权限。

## workdsh 报错怎么排查？

插件未显示时，可先确认当前 profile 是否正确、插件是否启用，再完整重启桌面版，检查版本与日志。企业功能不可用时，还应确认企业连接已激活、公司账号已登录；个人模式不提供企业认证服务。

README 中的 DSH Friends 示例明确要求安装后启用并完整重启 Desktop。它通过“插件 → 添加插件”安装 `dsh-friends@0.1.0-alpha.11`，属于独立社区扩展。

安装、界面或功能故障仍未解决时，先搜索仓库已有 Issues，再提交应用版本、个人或企业模式、复现步骤与错误截图。后台账号、权限和模型转发问题应提交给 WorkDSH Admin。公开反馈中不要包含密码、令牌、API 密钥或公司机密资料。
