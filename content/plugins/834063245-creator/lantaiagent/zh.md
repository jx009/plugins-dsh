## LantaiAgent 是做什么的？

LantaiAgent 是一个提供代码图谱查询的 DSH 插件条目，实际装入 DSH 的是仓库发布的 `@a834063245/hologram-dsh`。这款 DeepSeek Harness 插件将 HoloGram 引擎的 MCP 工具交给智能体，让它能在会话里查代码关系，而不必只靠逐个阅读文件来推断依赖。

仓库里的兰台是独立的 Windows 桌面工作台，提供可以并排摆放多个会话的画布；市场里的插件并不把这套界面搬进 DSH。它适合在接手代码库、评估重构范围或核对模块耦合时使用：先用关系图缩小阅读范围，再回到具体代码验证结论。

## LantaiAgent 核心功能

- **跨文件引用与变更影响**：引擎静态解析代码库并构建依赖图。准备改动某个文件或符号时，可以先查哪些代码引用它，以及依赖经过哪些模块，再决定要复核哪些文件。
- **循环依赖与脆弱模块**：查询模块间是否有依赖环路，也可以用引擎的分析结果排查脆弱模块和架构盲点。这些结果在查询时计算，不是建图时提前生成的固定报告。
- **执行流与数据流**：沿图谱检查调用关系和数据传递路径。动态导入会被标记为动态站点，不能把静态图谱当作一次真实运行的完整记录。
- **增量索引与新鲜度提示**：引擎可将文件变更增量合入图谱，失败时回退到全量处理。如果查询结果引用了索引之后又被修改的文件，引擎会提示结果可能不再反映当前源码。

## 怎么安装和使用 LantaiAgent？

仓库主 README 没有给出可直接复制的 DSH 安装命令。插件包名已列明，安装入口请查看仓库中的 `dsh-bundle/README.md`；不要把桌面版的 `.exe` 安装包当成 DSH 扩展。

1. 在 Windows x64 环境中，按插件包文档将 `@a834063245/hologram-dsh` 装到运行 DSH 网页端所用的 profile。配置时以 DSH 当前使用的 profile 为准，不要去兰台桌面端打开随包图谱开关。
2. 安装后重启 `dsh web`，在项目会话的智能体工具箱里查看是否出现以 `mcp__hologram__` 开头的工具。这些是图谱查询入口，不是新的可视化面板。
3. 第一次使用时，从一个明确的文件或符号开始。例如，给出你准备修改的函数名，请智能体先查跨文件引用，再把直接引用和需要进一步核对的依赖分开列出来。
4. 如果要排查循环依赖，可以先限定相关模块，请智能体列出环路中经过的模块，再逐个核对源码。遇到动态站点或结果新鲜度提示时，把这些位置视为待确认项。

## LantaiAgent 报错怎么排查？

- **工具没有出现**：核对安装和运行是否用了同一个 profile，确认插件处于启用状态，再重启 DSH 网页端。重新进入会话后，按工具前缀检查，不要用是否出现桌面画布来判断安装结果。
- **安装失败或重启后仍不可用**：先核对系统是否为 Windows x64，以及安装目标是否为图谱插件包。再检查 DSH 与插件版本，查看安装输出和启动日志，区分是安装未完成，还是启动时工具没有加载。
- **查询结果与当前代码不符**：先看结果是否带有新鲜度提示，并核对所查的文件或符号。若涉及动态导入，静态分析可能无法确定实际引用目标，仍需回到源码确认。
