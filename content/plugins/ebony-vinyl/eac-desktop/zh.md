## EAC-Desktop 是做什么的？

EAC-Desktop 是一个把项目会话、工具执行和插件管理放进原生窗口的开源 DSH 桌面工作台。它面向希望围绕项目目录使用 Agent 的开发者：发起任务后，可以在同一个工作台查看会话中的文件修改，也可以通过市场安装和管理扩展。它是独立发行的桌面应用，本身不是需要装进现有 profile 的 DeepSeek Harness 插件。

桌面窗口打开的是本地 Web UI，实际的会话和工具执行由 Harness 内核负责。模型请求则由你配置的提供商处理，安装桌面应用不会替换模型提供商。

## EAC-Desktop 核心功能

- **聚合插件市场**：在同一个目录里发现扩展，通过管理入口安装、启用或停用。内置、推荐和外部扩展的分发方式不同，能用哪些随包能力要看所选发行包。
- **插件快照与回滚**：保护中心提供快照、体检和回滚入口，用于管理扩展状态。要还原的是项目文件时，应查看会话的文件变更视图，而不是插件回滚入口。
- **会话文件变更**：在工作目录里发起任务后，可以按会话查看相关文件的修改，并从文件视图检查或还原变更。
- **视觉模型与人设配置**：通过快速配置入口管理视觉模型和人设相关设置。长对话中的上下文空间则由请求阶段的上下文压缩和有界溢出恢复辅助管理。
- **DPX 独立环境**：桌面端使用 `web-desktop` profile，默认数据路径和运行时变量由环境管理。同一发布通道复用环境，不同通道的数据分别存放。

## 怎么安装和使用 EAC-Desktop？

从仓库的 Releases 页面下载桌面发行包。README 没有提供将 EAC-Desktop 本体作为 DSH 插件安装的命令。

1. 按系统和架构选包。Windows x64 有 Full Setup 和 Lite Setup；Linux x64 有 AppImage 和 deb；macOS arm64 使用 DMG。各平台发布的版本可能不同，下载前看对应文件的版本号。
2. 启动桌面应用。程序会准备桌面 profile，再使用随包运行时启动本地 Web UI；普通使用不需要提前安装 Node.js 或 npm。
3. 选择项目工作目录并发起会话。需要调整视觉模型或人设时，打开快速配置入口；任务完成后，可在文件视图里核对本次会话关联的改动。
4. 需要额外能力时，在插件市场查找并安装扩展，再检查启用状态。兼容范围和附加依赖以实际发行包及插件配置为准。

## EAC-Desktop 报错怎么排查？

- **启动后未进入 Web UI**：先确认安装包版本，再查看启动日志。如果 DPX 环境初始化失败，应用会中止启动并记录错误，而不是继续使用不正确的数据根。
- **插件不显示或没有生效**：先确认正在查看目标发布通道里的 `web-desktop` profile，再核对扩展是否随包提供或已单独安装、是否启用。重启桌面应用后仍不显示，再检查版本和日志。
- **找不到原来的会话或设置**：先核对发布通道，不要直接覆盖目录。Windows 默认产品数据根是 `%LOCALAPPDATA%\Deepseek Harness EAC`，通道环境位于其 `dpx/dsh-environments/eac-<channel>/` 下。备份时先退出应用，再保存实际产品数据根与独立的项目目录；便携包也不能仅凭程序所在目录判断数据位置。
