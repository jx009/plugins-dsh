## dsh-our-free-model 是做什么的？

dsh-our-free-model 为 DeepSeek Harness 增加模型渠道与路由能力，覆盖匿名免费网关、需要登录的账号渠道，以及自行配置的第三方提供商。它也支持接入 Ollama、LM Studio、llama.cpp 等本地服务。

模型清单、上下文长度和能力信息在刷新时从上游获取。免费渠道的实际访问仍受上游配额、地区策略和服务状态影响。

## 核心功能

- 免费渠道直连 OpenCode Zen 与 Kilo AI；其他渠道可通过账号登录或自有凭据接入。
- 根据模型支持情况，将思考档位或输出 Token 预算传给上游。
- 将命名路由链注册为 `combo:<name>` 虚拟模型，支持顺序降级和轮询；正文开始输出前的失败可触发模型切换。
- 本地网关提供 OpenAI 兼容调用及 Anthropic 接口，包括 `/v1/messages` 和本地 Token 数量估算。
- 本机看板记录 Token 消耗、生成速度与首字延迟，并提供可选的工具输出压缩等请求处理能力。
- 应用内升级包含校验与失败回滚，热重载可在不重启应用的情况下应用变更。

## 怎么使用 dsh-our-free-model

提供的 README 片段未包含 DSH 安装命令，仓库信息也未确认 npm 包名，因此这里不生成安装命令。

安装后，在设置页查看免费渠道、连接账号或配置提供商。需要凭据的提供商使用你自己的 Key；支持免账号接入的本地服务可直接配置。

在 DSH 中选择模型，或创建路由链。其他客户端可使用网关页面按实际端口和鉴权要求生成的接入示例。模型渠道也支持在 `dsh-tui` 等没有 Web 服务的组合中启动。

发送提示词前，应了解所选上游的数据处理方式。用量统计留在本机，并不意味着推理请求也留在本机。
